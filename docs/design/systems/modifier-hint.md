# Modifier-hint 오버레이

**Modifier-hint** 는 modifier 를 홀드하는 동안 눌린 조합을 포함하는 단축키 목록을 보여 주고 키를 떼면 사라지는 오버레이다 — Modal · Popup · Toast · Banner 에 이은 다섯 번째 오버레이 개념. 용어 정의는 [concepts/ubiquitous-language](../../concepts/ubiquitous-language.md), 토큰 매핑은 [design-token-mapping](design-token-mapping.md) 의 modifier-hint 절이다.
