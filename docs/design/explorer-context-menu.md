# Explorer Context Menu

Explorer 파일 트리의 우클릭 컨텍스트 메뉴 동작 정의.

## 우클릭 대상 결정

```
우클릭 시점의 상태:
├── 우클릭 대상이 선택 목록에 포함됨
│   → 선택된 전체가 메뉴 대상 (VS Code/Finder 방식)
│
└── 우클릭 대상이 선택 목록에 포함되지 않음
    → 기존 선택 초기화, 우클릭 항목만 선택
    → 우클릭 항목 하나가 메뉴 대상
```

배경(빈 영역) 우클릭:
- 선택 상태 변경 없음
- 메뉴 대상: Explorer의 현재 cwd (`root_path`)

## 메뉴 항목 결정

대상 목록의 구성에 따라 메뉴 항목이 달라진다:

| 메뉴 항목 | 배경 | 파일 단일 | 폴더 단일 | 다중 선택 |
|-----------|------|-----------|-----------|-----------|
| 경로 복사 | cwd 경로 | 파일 경로 | 폴더 경로 | 모든 경로 (개행 구분) |
| 즐겨찾기 추가/삭제 | cwd 대상 | - | 폴더 대상 | - (숨김) |
| 복사 | - | O | O | O |
| 삭제 | - | O (휴지통) | O (휴지통) | O (휴지통) |

**즐겨찾기 규칙**: 다중 선택 시 즐겨찾기 항목은 항상 숨김. 즐겨찾기는 단일 폴더 선택 또는 배경 우클릭에서만 표시.

## 각 액션의 동작

### 경로 복사

- 단일: 해당 경로를 OS 클립보드에 복사
- 다중: 선택된 모든 경로를 개행(`\n`) 구분으로 OS 클립보드에 복사
- 배경: cwd (`root_path`) 복사

### 즐겨찾기 추가/삭제

- **단일 폴더 또는 배경에서만 표시** (다중 선택 시 숨김)
- 대상 폴더가 이미 즐겨찾기면 "즐겨찾기 삭제" 표시 → 삭제
- 아니면 "즐겨찾기 추가" → 이름 입력 팝업 → 추가
- 배경 우클릭: cwd를 대상으로 동일 로직

### 복사 (파일 클립보드)

- 선택된 파일/폴더를 OS 파일 클립보드에 복사
- 기존 `explorer_file_copy()` 로직 재사용

### 삭제 (휴지통)

- `trash` 크레이트로 OS 휴지통에 이동
- 삭제 후 Explorer 트리 갱신
