# ADR-0142: 채널 주장은 작업 트리 기준으로 쓴다 — 원격 층은 오프라인으로 못 고정한다

- **Status**: Accepted
- **Date**: 2026-09-05
- **Tags**: ci, docs, guards, remote, push, observability, adr-0133, adr-0138, adr-0139

## Context

"이 가드는 CI 가 자동으로 돌린다" 는 서술이 참이려면 층이 넷 다 참이어야 한다. 이 ADR 이
다루는 것은 셋째 층이다.

1. **명령** — 자동 잡의 명령이 그 타깃을 실제로 돌리는가(`--lib --bins` 는 통합 타깃을
   못 본다).
2. **발화** — 그 잡의 트리거가 그 타깃을 위반할 수 있는 변경에 발화하는가(`paths-ignore`).
3. **원격** — 그 트리거와 명령이 **GitHub 이 읽는 ref** 에 가 있는가.
4. **결과** — 그 잡이 초록이고 그 결과가 읽히는가([ci-gates](../dev-guide/ci-gates.md)).

①② 는 워크플로 파일을 읽어 판정할 수 있고 `ci_channel_claims_match_workflows` 가
그렇게 한다. 셋째는 다르다. GitHub 은 원격의 워크플로 파일을 읽으므로, 로컬에서 트리거나
명령을 고쳐도 push 전까지 아무 일도 일어나지 않는다. 이 저장소는 로컬 main 이 원격보다
크게 앞서는 기간이 길어 그 층이 실제로 벌어진다.

이 층이 실제로 얼마나 벌어지는지, 그리고 얼마나 빨리 닫히는지를 하루 사이에 양쪽으로
측정했다. 원격 워크플로 **전문**을 받아 작업 트리와 대조하는 방식이다(수단은
[ci-gates](../dev-guide/ci-gates.md) 의 "트리거는 어느 ref 의 것인가").

- **push 전** — 워크플로 파일 둘이 원격에 아예 없었고, `complexity-check` 의 push 트리거가
  없었고, 원격 `check-headless` 의 명령이 `--lib --bins` 라 통합 타깃을 하나도 안 봤다.
  그중 가장 큰 것은 트리거가 아니라 **명령**이었다 — 트리거만 대조했으면 못 봤다.
- **push 후** — 세 갈림이 한꺼번에 닫혔다. 같은 census 를 다시 돌리니 ③층 거짓이
  **마흔넷에서 0** 이 됐다. 문장은 한 줄도 안 고쳤다.

**이 대비가 이 ADR 의 근거 전부다.** 마흔넷은 문서의 결함이 아니라 미push 상태의
그림자였다. 문장마다 ③층 조건절을 달았다면 그 조건절 마흔넷이 push 하나로 한꺼번에
거짓이 됐을 것이다 — 낡을 자리를 줄이는 게 아니라 늘리는 형태다.

측정 하나를 더 남긴다. **워크플로 파일이 그 push 로 처음 들어가도 GitHub 은 그 push 에
대해 발화시킨다** — 원격에 존재한 적 없던 워크플로 둘이 자기를 들여보낸 push 에서 그대로
돌았다. "새 워크플로는 다음 push 부터" 라는 흔한 가정은 틀렸고, 그래서 ③층의 갈림은
push 한 번으로 완전히 닫힌다.

## Decision

**개별 문장은 작업 트리 기준으로 쓰고, ③층은 한 곳에서만 — 값이 아니라 재는 법으로 —
말한다.**

- 이 레포의 채널 서술은 `.github/workflows/` 의 **작업 트리 파일**을 가리킨다. 그것이
  가드가 실제로 검사하는 층(①②)이기도 하다.
- ③층은 [ci-gates](../dev-guide/ci-gates.md) 의 한 절에서만 다루고, 그 절은 **현재값을
  안 적는다.** 두 ref 의 차분은 push 마다 움직이므로
  [ADR-0139](0139-numbers-in-docs-are-classified-by-lineage-not-by-name.md) 의 칸 1 이고,
  그 처방대로 **재는 명령**과 **과거형 사례**로만 적는다. 다른 곳에서는 그 절을 가리킨다.
- 예외 하나 — **원격의 사실을 주장하는 문장**("실제로 발사됐다 / 발사된 적이 없다")은
  어디에 있든 관측 좌표(측정 시각 또는 재는 명령)를 같은 서술에 단다. 좌표 없는 원격
  주장은 반증할 방법이 없다.

**이 ADR 의 첫 판(초안)이 정확히 그 함정에 빠졌다.** ③층 값을 "그날의 판정" 이라는
이름으로 한 곳에 모아 적었는데, 모아 놓아도 차분은 차분이라 다음 push 에 통째로 낡았다.
ADR-0139 의 계보 분류가 그것을 잡았다 — **한 곳에 모으는 것과 안 낡게 만드는 것은 다른
문제**이고, 이 ADR 은 앞의 것만 했다.

문장마다 "단 아직 push 되지 않았다" 를 달지 않는 이유는 대칭이다 — **push 하는 날 그
수십 곳이 한꺼번에 거짓이 된다.** 조건절은 낡을 자리를 줄이지 않고 늘린다.

**③층에는 자동 채널이 없다.** 이것을 감추지 않고 선언한다 — `cargo test` 안에서는 원격을
볼 수 없고, 볼 수 있게 만드는 세 방법이 모두 더 나쁘다(아래 Alternatives).

**대신 ①②층은 더 좁힌다.** ③층을 못 박지 못하는 만큼, 작업 트리 기준으로 거짓인 서술
(위 층 구분에서 ③을 뺀 나머지)은 남김없이 기계가 잡게 한다.
`ci_channel_claims_match_workflows` 의 부재 축을 둘로 넓혔다.

- **모듈 doc 의 암묵 주어** — 통합 타깃의 `//!` 는 "이 테스트는 …" 이라고 쓰지 자기
  경로를 부르지 않는다. 지목이 없다는 이유로 건너뛰면 이 축은 **가드 자신의 채널 서술을
  통째로 못 본다.**
- **배타 주장** — "X 잡에서만 일어난다" 는 부재 어휘를 하나도 안 쓰면서 X 밖의 채널을
  부정한다. 조합이 하나에서 둘로 늘어난 타깃이 옛 잡 하나만 적은 채 살아 있었다.

두 축을 켜자 **열세 자리**가 걸렸고 전부 실제로 거짓이었다(같은 회차에서 고쳤다).

## Consequences

- **얻은 것**: 그 시점의 ③층 거짓 마흔넷이 규약 한 줄로 사라졌다. push 해도, 안 해도
  문장이 안 낡는다.
- **얻은 것**: ③층이 관측 가능해졌다 — `gh api …/contents/<파일>?ref=main` 은 로컬
  remote-tracking ref 를 안 타므로 그것이 낡았을 가능성과 무관하다. `gh run list` 가
  조회에 실패하는 것 자체가 "원격에 그 파일이 없다" 의 신호다.
- **잃은 것**: 문서만 읽는 사람은 "지금 이 순간 CI 가 나를 지켜 주는가" 를 한 문장에서
  알 수 없다. 한 번 더 눌러야 한다(그 절로). 그 대신 그 한 곳은 틀리지 않는다.
- **운영 비용**: push 할 때마다 그 절의 좌표가 낡는다. 좌표가 낡았다는 것 자체는
  해롭지 않다 — 값이 아니라 **언제 잰 값인지**가 적혀 있기 때문이다.

## Alternatives Considered

- **원격 스냅샷을 커밋해 테스트로 대조** — 오프라인에서 ③층을 판정할 수 있게 된다.
  기각: 스냅샷은 사람이 갱신해야 하고, **사람이 갱신을 잊는 형태**가 정확히
  [ADR-0133](0133-guard-scan-population-is-pinned-not-enumerated.md) 이 막으려는 실패다.
  낡은 스냅샷은 틀린 판정을 조용히 내놓는다.
- **`git show origin/main:<파일>` 로 대조** — 기각: 로컬 remote-tracking ref 가 최신이라는
  보장이 없다. `git fetch` 를 먼저 돌려야 참이 되는데, 그러면 판정이 네트워크와 로컬 ref
  상태 둘 다에 의존한다. 같은 값을 `gh` 로 직접 받으면 ref 를 아예 안 탄다.
- **문장마다 조건절** — 기각: 위 대칭 이유.
- **가드가 네트워크를 쓴다** — 기각: `cargo test` 가 네트워크에 의존하면 오프라인에서
  빨개지고, 그 빨강은 코드와 무관하다.

## Reconsideration Triggers

다음 중 하나가 충족되면 본 ADR 을 재검토한다.

- 이 저장소가 커밋마다 push 하는 흐름으로 바뀐다 — 로컬과 원격이 거의 안 갈리면 ③층을
  따로 말할 이유가 줄고, 개별 문장이 곧 원격 사실이 된다.
- ③층을 도는 자동 잡이 생긴다(예: `gh` 로 원격 워크플로를 대조하는 워크플로) — 그러면
  "자동 채널 없음" 선언이 만료되고, 선언을 지우고 검사를 넣는다.
- ci-gates 의 그 절이 둘 이상으로 쪼개진다 — 값이 한 곳에 있다는 전제가 깨진다.
