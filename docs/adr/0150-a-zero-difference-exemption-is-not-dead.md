# ADR-0150: 차집합이 0 인 면제는 죽은 것이 아니다 — 죽음과 잠복은 사유가 가른다

- **Status**: Accepted
- **Date**: 2026-09-05
- **Tags**: guards, exemptions, measurement, adr-0133, adr-0146

## Context

면제가 여러 겹인 가드에서 **한 겹이 실제로 하는 일은 다른 겹과의 차집합**이다. 겹치는
부분은 그 겹이 없어도 덮이므로 그 겹의 효과가 아니다.

그 차집합을 실제로 재보니 0 인 항목이 나왔다. 자연스러운 처방은 "지워라" 다 — 아무것도
덮지 않는 면제는 다음 사람에게 "여기는 원래 위반해도 된다" 는 잘못된 신호를 주므로.

**그 처방이 틀렸다.** 차집합 0 인 항목을 실제로 읽어 보니 전부 정책 면제였다.

## Decision

**차집합이 0 이라는 것만으로 면제를 지우지 않는다.** 0 은 죽음의 증거가 아니라 "지금
덮을 것이 없다" 는 뜻이고, 죽음과 잠복을 가르는 것은 측정이 아니라 **면제에 적힌 사유의
종류**다.

| 사유의 형태 | 차집합 0 일 때 | 처방 |
|---|---|---|
| "이 파일이 지금 X 때문에 위반한다" | X 가 사라졌다 — 죽음 | 지운다 |
| "이 경로는 검사 범위 밖이다"(정책) | 정책은 그대로 — 잠복 | 둔다 |

**그리고 이 판정을 가드로 만들지 않는다.** "모든 면제의 차집합이 0 이 아니다" 를 단정하면
초록이 "모든 면제가 지금 무언가를 덮는다" 를 뜻하게 되고, 그것은 정당한 잠복 면제를
지우라고 몰아간다. 만들 수 있는 것은 참조 무결성뿐이다.

재는 절차와 방법별 신뢰도는 [guard-population.md](../dev-guide/guard-population.md) 의
해당 절.

## Consequences

- **얻은 것**: 면제를 지울 근거가 "안 덮는다" 가 아니라 "사유가 사라졌다" 로 분명해진다.
  정책 면제를 실수로 지우는 경로가 막힌다.
- **잃은 것**: 죽은 면제를 자동으로 찾지 못한다. 차집합 측정은 후보를 좁혀 주지만
  마지막 판정은 사람이 사유를 읽어야 한다.
- **운영 비용**: 항목 단위 측정은 항목마다 재컴파일이라 전수에는 비싸다. 겹 단위 측정을
  먼저 돌려 후보를 좁힌 뒤 항목 단위로 확인하는 순서가 실측상 가장 쌌다.

### 실측 (2026-09-05)

면제 겹 13 · 항목 100 개(`FORBIDDEN*` 계열은 탐지 대상이라 제외). 겹 단위로 6 겹을
비워 돌린 결과 **전부 빨개졌다** — 겹 단위로 죽은 것은 없었다. 그중 30 항목을 항목
단위로 재어 차집합 0 이 넷 나왔고, **넷 다 잠복이었다**: 셋은 doc 이 "영구 허용 경로"
라고 명시한 것이었고, 하나는 i18n 규약의 예외를 그대로 옮긴 것이었다.

방법별로 결과가 갈렸다. 정적 패턴 추출로 판정하려 한 시도는 이 축에서 **여섯 번 전부**
양방향으로 틀렸다(순회 시작점을 `strip_prefix` 호출로 오인 · 함수 정의를 재귀 호출로
계수 · 무관한 상수를 가지치기 이름으로 추출 · 목록 범위가 파일 끝까지 흐름 · 후행 콤마를
원소로 계수 · 위반 출력의 이름 일치로 항목 생사 판정). 답한 것은 변이와, 금지 패턴을
대상 파일에 직접 세는 것뿐이었다.

## Alternatives Considered

- **A. 차집합 0 인 면제를 지운다** — 기각. 실측한 넷이 전부 정책 면제였다. 지웠다면
  "이 경로는 검사 범위 밖" 이라는 결정이 조용히 뒤집혔을 것이고, 되살아나는 것은 그
  경로가 다시 무언가를 담을 때다 — 즉 **원래 통과해야 할 것이 그때 빨개진다.**
- **B. "차집합이 0 이 아니다" 를 가드로 단정한다** — 기각. 초록의 뜻이 틀리다(위 Decision).
  덧붙여 이 판정은 가드 안에서 할 수 없다 — 항목을 빼고 다시 도는 것이 필요하고, 그것은
  자기 소스를 고쳐 재컴파일하는 일이다.
- **C. 사유의 종류를 타입으로 박는다**(면제마다 `Backing` 류 열거형) — 기각. 갈래가 둘
  (위반 기반 · 정책 기반)이고 자리가 흩어져 있어, 틀을 세우는 비용이 지금 얻는 것보다
  크다. 갈래가 늘면 재검토한다.
- **D. 참조 무결성 검사를 모든 겹에 붙인다** — 부분 채택. 이 저장소에 둘 있고 둘 다
  이름이 재는 것보다 더 약속하고 있어 이름을 고쳤다. 나머지 겹에 붙이는 것은 이
  ADR 의 범위 밖이다 — 차집합과 다른 축이고, 값은 있으나 급하지 않다.

## Reconsideration Triggers

다음 중 하나가 충족되면 본 ADR 을 재검토한다.

- **차집합 0 인 면제 중 죽은 것이 실제로 발견된다** — 이 ADR 은 실측 넷이 전부 잠복이었다는
  관측 위에 서 있다. 죽은 사례가 나오면 "사유를 읽어라" 만으로 충분한지 다시 본다.
- **사유의 갈래가 셋 이상이 된다** — C 를 다시 본다.
- **면제 겹 수가 크게 늘어 사람이 사유를 읽는 것이 실효를 잃는다** — 전수 판정이
  불가능해지면 후보를 좁히는 자동 수단이 필요해진다.
