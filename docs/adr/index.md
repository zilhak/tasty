# 원칙의 예외와 미충족 결정

ADR은 [제품 원칙](../principles/index.md)의 예외나 일부 미충족을 채택한 결정을 기록한다. 원칙을 준수하는 일반 설계는 현재 설계·기능·개발 문서에 적는다. 원칙 간 충돌과 해소한 우선순위는 관련 원칙 문서에 남긴다.

현재 채택된 예외 ADR은 없다. 첫 예외는 1번부터 시작한다. 과거와 번호가 같아도 같은 결정이 아니다. 이전 문서의 목적지는 [문서 이동표](../dev-guide/adr-migration.md)에 있다.

## 작성과 관리

[작성 양식](template.md)에 따라 관련 원칙·벗어나는 범위·이유를 설명한다. 기존 구현의 미충족만으로 예외가 채택된 것으로 취급하지 않는다.

첫 ADR을 추가할 때 빈 집합 표식을 지우고 해당 Group의 생성 구역을 만든다. [인덱스 관리](../dev-guide/adr-index.md)의 도구로 행을 생성한다.
