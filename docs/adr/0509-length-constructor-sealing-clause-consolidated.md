# ADR-0509: 길이 타입 튜플 생성자는 봉인하지 않는다 — ADR-0128 · ADR-0145 · ADR-0169 의 봉인 조항 통합

- **Status**: Accepted
- **Date**: 2026-09-23
- **Tags**: typed-length, dpi, guards, sealing, adr-conventions, adr-0128, adr-0145, adr-0169, adr-0506, adr-0148

## Context

`PhysicalPx(pub f32)` / `LogicalPx(pub f32)`(`crates/tasty-type-geometry/src/length.rs`) 의 튜플
필드를 비공개로 봉인하는가 — 이 한 조항을 세 ADR 이 서로 인용하지 않은 채 각자 결정했다.

| | ADR-0128 | ADR-0145 | ADR-0169 |
|---|---|---|---|
| 결론 | 봉인이 아니라 소스 스캔 가드로 지킨다 | **당분간** 열어 둔다 | 봉인하지 않는다 |
| 기각 근거 | 봉인이 잡을 형태가 65 건 중 4 건, 이식 뒤 생성자를 거치는 DPI 변환 0 | 이득은 정확성이 아니라 **판정기 정밀도**, 비용은 병렬 lane 전역의 통합 비용 | 탈출구가 곧 같은 단언 — 생성자 자리를 전부 바꿔 면제표 13 자리의 사각을 지운다 |

결론은 같지만 **재검토의 출발점이 다르다.** 0145 만 읽은 사람은 "통합 비용이 줄면 봉인 쪽으로"
에서, 0128·0169 만 읽은 사람은 "막을 대상이 없다" 에서 출발한다. 운영 문서도 갈라져 있었다 —
`docs/concepts/typed-length.md` 는 0128 을, `docs/ai-verification/dpi-scale-verification.md` 는
0145 를 "정적 축의 현재 결정" 으로 가리켰다.

세 문서의 겹침은 **이 조항 하나**이고 각자 독립 조항을 가져
[ADR-0506](0506-a-decision-recorded-twice-is-split-by-the-width-of-the-overlap.md) 의 **조항 겹침**
이다. 그래서 원본 어느 것도 Supersede 하지 않고 조항만 여기로 모은다.

### 다시 잰 수 (2026-09-23, `3d0ec08ef`)

원본의 수는 서로 다른 술어의 시점 값이라 옮겨 적지 않았다. **술어**: 출하되는 코드만 본다 —
`strip-cfg-test --blank-test-only-files` 로 `#[cfg(test)]` 블록과 시험 전용 파일을 비우고
`mask-source` 로 주석·문자열을 덮은 `src` · `crates` 사본에서, `tests` · `benches` · `examples`
디렉토리를 뺀 `.rs` 의 정규식 출현을 센다.

| 재는 것 | 정규식 | 수 |
|---|---|---|
| 생성자 출현(구조체 정의 두 줄 포함) | `\b(PhysicalPx\|LogicalPx)\(` | 953 (`LogicalPx` 868 · `PhysicalPx` 85) |
| 그중 인자가 숫자 리터럴 하나 | `\b(PhysicalPx\|LogicalPx)\(\s*-?[0-9][0-9_.]*(f32)?\s*\)` | 593 |
| 변환 호출 | `\.to_(physical\|logical)\(` | 50 |
| 인자 안에 배율 산술이 든 `PhysicalPx(` | `\bPhysicalPx\([^()]*[*/][^()]*\b(ppp\|scale_factor\|sf\|pixels_per_point)\b` | **1** — `to_physical` 본체(`length.rs`) |
| `PhysicalPx(..).0` · `LogicalPx(..).0` 직접 접근 | `\b(PhysicalPx\|LogicalPx)\([^()]*\)\.0\b` | 0 |
| `ALLOWED`(`src/dpi_conversion_guard.rs`) | 표의 항목과 건수 | 4 파일 · 13 자리(2 · 8 · 1 · 2) |

## Decision

**튜플 필드를 봉인하지 않는다.** 이 축의 집행은 `src/dpi_conversion_guard.rs` 가 한다.

**현재 판단으로 채택하는 근거**:

- **막을 대상이 없다**(0128 · 0169). 봉인이 막으려는 형태 — `PhysicalPx(x * ppp)` 에서 `* ppp`
  를 빠뜨리는 것 — 가 출하 코드에 한 자리뿐이고 그 한 자리가 변환 함수의 몸통이다. 나머지
  `PhysicalPx` 는 곱할 배율이 애초에 없는 값(장치가 물리로 주는 좌표·크기와 상수)이다.
- **탈출구가 곧 같은 단언이다**(0169). 본래 물리인 입력과 상수에는 f32 에서 만드는 길이 필요하고,
  그 길(`from_raw` 든 어떤 이름이든)은 오늘의 생성자처럼 검증이 아니라 단언이다. 봉인은 생성자
  자리를 전부 이름만 바꿔 다시 단언하게 만든다.
- **봉인의 이득은 판정기 정밀도이고 크기가 정해져 있다**(0145 · 0169). 가드의 바늘이 줄 단위
  휴리스틱에서 정확한 심볼로 바뀌어, 가드가 붙박아 둔 거짓 음성(줄이 갈린 산술 · 매크로 생성
  코드 · 등재 파일 안에서 건수를 유지한 이동)이 사라진다. 그 노출면은 `ALLOWED` 4 파일 13 자리이고
  넷 다 산술이 있는 것이 정상인 자리다.
- **봉인이 못 지우는 것은 이득에 세지 않는다**(0169). "변환을 빠뜨린 것" 이 아니라 "애초에 타입이
  틀린 것"(물리 타입에 논리 값을 넣는 것)은 봉인해도 통과한다.

**기각하는 근거**: **"비용이 병렬 lane 의 통합 비용이라 당분간 미룬다"**(0145). 통합 비용이 0 이어도
위 두 근거(막을 대상이 없다 · 탈출구가 같은 단언)는 그대로 선다 — 비용은 결정을 가르지 않는다.
그래서 0145 의 재검토 조건 "병렬 lane 이 정리되어 통합 비용이 낮아지면" 은 이 조항의 재검토 조건에서
뺀다.

**통합하지 않는 조항** — 원본에 남아 유효하다:

- **ADR-0128**: 봉인 대신 택한 집행 수단 셋 — 스캔 가드(`ALLOWED` 를 사유·건수로 등재) · 짝 타입
  (`PhysicalRect` ↔ `LogicalRect`, `WebViewBounds` ↔ `PhysicalWebViewBounds`) · 왕복 상쇄 시험
  (`physical_and_logical_round_trip_cancels`).
- **ADR-0145**: 면제의 근거를 검사 가능하게 만든다 — `ALLOWED` 사유 넷 중 사실 진술 셋을 시험이
  단정하고, 넷째(폰트 크기는 길이가 아니다)는 검사할 수 없다고 적는다. 그리고 봉인 규모를
  컴파일러로 잰 절차(`pub(crate)` 로 바꾸고 `cargo check --keep-going`).
- **ADR-0169**: `ALLOWED` 가 건수 대신 식 자체를 못박는 대안이 **기각이 아니라 미착수**라는 판단과,
  줄 번호를 못박는 대안의 기각.

## Consequences

- **얻은 것**: 봉인 조항의 현재 서술과 재검토 출발점이 한 자리에 있다. 두 운영 문서가 이 ADR 에
  닿는다.
- **잃은 것**: 생성은 계속 단언이다. 가드의 붙박은 거짓 음성 셋이 남는다.
- **운영 비용**: 없다 — 현행 유지다. 위 표의 수는 커밋마다 움직이므로 재검토할 때는 옮겨 적지
  말고 같은 술어로 다시 잰다.

## Alternatives Considered

- **봉인하고 `to_physical`/`to_logical` 만 남긴다** — 본래 물리인 입력과 상수에 탈출구가 필요하다.
  기각(0169).
- **봉인하되 이름 있는 탈출구(`from_raw` · `from_device`)** — 검증력은 오늘과 같다. 이름이 주는
  정보("이 자리는 장치 입력이다")는 봉인 없이 이름만 도입해도 얻는다. 기각(0145 · 0169).
- **크레이트 단위로 나눠 순차 봉인** — 튜플 필드의 가시성은 크레이트로 나눌 수 없다. 원리적으로
  불가능(0145).
- **`#[deprecated]` 로 유도** — 튜플 생성에 붙일 자리가 없다(0145).
- **원본 중 하나를 남는 쪽으로 골라 흡수** — 기준(가장 이른 것 · 운영 문서가 인용하는 것 · 근거가
  두꺼운 것)이 셋 다 다른 답을 낸다. ADR-0506 이 그 선택을 절차에서 뺐다.

## Reconsideration Triggers

다음 중 하나가 충족되면 본 ADR 을 재검토한다.

**채널이 붙는 것** — 판정 시점에 레포가 읽을 수 있는 사실이다.

- 인자 안에 배율 산술이 든 `PhysicalPx(` 가 변환 API 본체 밖에 생기면 — "막을 대상이 없다" 의
  전제가 깨진다(0128 "생성자를 거치는 변환이 지배적이 되면" 과 같은 조건을 수로 적었다). 재는
  술어는 위 표 넷째 줄이다.
- `ALLOWED` 가 커지면 — 등재 파일이 늘거나 한 파일의 건수가 자라면 거짓 음성의 노출면이 커져
  봉인(또는 식을 못박는 대안)의 이득이 커진다(0169).
- `.0` 직접 접근이 늘면 — 지금 0 이라 봉인 비용의 절반이 없는 상태다(0145).
- 생성자 출현 수가 줄기 시작하면 — 리터럴 상수가 토큰으로 흡수되고 있다는 뜻이고 봉인 비용의
  크기가 달라진다(0169).
- 가드의 자동 실행 채널이 사라지면 — 이 결정은 봉인을 가드로 대신한 것이라 가드가 안 돌면 대신이
  성립하지 않는다(0128). 채널의 정본은 `docs/dev-guide/ci-gates.md`.

**원리적으로 안 붙는 것** — 사람이 관측해야 한다. 재는 법을 함께 적는다.

- 본래 물리인 입력(winit 좌표·GPU 크기)이 전부 타입을 달고 들어오게 되어 f32 에서 `PhysicalPx` 를
  만들 이유가 사라지면(0169). 재는 법: 인자가 리터럴이 아닌 `PhysicalPx(` 자리를 읽어 장치 입력인지
  가른다.
- 가드의 붙박은 거짓 음성이 **실제 결함을 놓친 사례**나 변환을 빠뜨린 생성이 **실제 좌표 버그**로
  보고되면(0145 의 두 조건을 합쳤다 — 둘 다 "판정기 정밀도가 이론적 이득이 아니게 된다" 를 뜻한다).
  재는 법: 좌표 버그 수정 커밋의 원인이 생성자 자리였는지 본다.
- 스캔이 구문 분석 없이는 가를 수 없는 오탐·누락을 반복해서 내면 — 강제 수단을 린트나 타입
  수준으로 올리는 쪽을 다시 본다(0128). 재는 법: `dpi_conversion_guard` 의 면제·수정 이력.

**뺀 조건**: 0145 의 "병렬 lane 이 정리되어 통합 비용이 낮아지면" — 위 Decision 의 기각 근거대로
비용은 이 조항을 가르지 않는다.
