# 국제화 (i18n)

모든 UI 문자열은 `t()` 함수를 통해 번역 키로 노출한다. 코드에 영어/한국어/일본어 문자열을 직접 하드코딩하지 않는다.

## API

`tasty_core::i18n` 모듈 (본 바이너리에서는 `crate::i18n` 으로 재수출):

```rust
pub fn t(key: &str) -> &str;
pub fn t_fmt(key: &str, arg: &str) -> String;
pub fn current_language() -> &'static str;
pub fn register_namespace(plugin_id: &str, lang_dir: &Path) -> Result<()>;
pub fn unregister_namespace(plugin_id: &str);
```

- `t(key)` 가 키를 못 찾으면 키 문자열 그대로 반환 — 누락이 화면에 그대로 드러나 회귀를 즉시 발견하게 한다.
- `t_fmt(key, arg)` 는 키 값 안의 `{}` placeholder 를 `arg` 로 치환한다 (단일 인자).

## 사용 패턴

```rust
// ✅ 올바름 — 번역 키 사용
ui.label(t("settings.appearance.custom_font_label"));
ui.heading(t("settings.performance.heading"));

// ❌ 금지 — UI 문자열 하드코딩
ui.label("Custom font file:");
ui.heading("Performance");
```

## 번역 파일 위치

| 대상 | 경로 | 로드 시점 |
|------|------|----------|
| 본 바이너리 임베드 | `lang/{en,ko,ja}.toml` (워크스페이스 루트) | 시작 시 `include_str!` |
| 번들/외부 plugin | `crates/<plugin>/lang/{en,ko,ja}.toml` 또는 plugin 설치 디렉토리 `lang/` | plugin 활성화 시 `register_namespace` |
| 사용자 커스텀 오버라이드 | `~/.tasty/lang/{code}.toml` | 시작 시 베이스 위에 overlay |

언어 선택은 `~/.tasty/config.toml` 의 `general.language` 필드 (`en` / `ko` / `ja`). 변경하려면 재시작 필요.

오버레이 계층: 영어 베이스 → 선택 언어 → 사용자 커스텀 순서로 덮어쓰기. 누락된 키는 한 단계 아래로 fallback.

## 새 문자열 추가 절차

1. 코드에 `t("namespace.key")` 호출을 먼저 추가.
2. `lang/en.toml`, `ko.toml`, `ja.toml` (워크스페이스 루트) **세 파일 모두** 같은 키를 추가. 누락하면 fallback 으로 영어가 보이거나 키 문자열이 화면에 그대로 노출된다.
3. plugin 의 문자열이면 해당 plugin 의 `lang/` 디렉토리에 추가.

키 네이밍: `<영역>.<서브영역>.<항목>` (예: `settings.appearance.theme_label`). 점으로 계층 구분.

## Plugin 의 번역 네임스페이스

Plugin 이 활성화될 때 `register_namespace(plugin_id, &lang_dir)` 가 호출되어 해당 plugin 의 번역이 overlay 로 합쳐진다. 키 충돌을 피하려면 plugin 은 자기 키를 `<plugin_id>.<...>` 로 prefix 한다. Plugin 비활성화/제거 시 `unregister_namespace` 로 안전하게 정리.

문자열은 `Box::leak` 되어 `&'static str` lifetime 을 만족한다. 네임스페이스 등록/해제가 잦으면 메모리 누수가 누적될 수 있지만 plugin 활성화 빈도가 낮아 무시할 수준.

## 하드코딩 허용 예외

번역하면 의미가 변하는 고유명사는 하드코딩 허용:

- 수식키 이름: `Ctrl`, `Alt`, `Shift`, `Cmd` 등
- 폰트 프리뷰 텍스트: `AaBbCcDdEeFfGg`
- 언어 이름 자체: `English`, `한국어`, `日本語`
- 단축키 조합 표시: `Ctrl+Shift+P` 같은 키 시퀀스

그 외 모든 사람이 읽는 문자열은 예외 없이 `t()` 로 노출한다.
