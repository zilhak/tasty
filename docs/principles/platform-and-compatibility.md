# 플랫폼과 버전 호환성

## 1급 지원

Windows, macOS, Linux를 1급 지원한다. macOS는 Apple Silicon만 지원한다.

| 플랫폼 | 아키텍처 | 지원 | 개발자의 직접 검증 환경 |
|---|---|---|---|
| Windows | x64 | 1급 | 있음 |
| Windows | ARM | 1급, 릴리스 포함 | 제대로 된 동작 확인 환경 없음 |
| macOS | Apple Silicon | 1급 | 있음 |
| Linux | ARM·x64 | 1급 | 있음 |

검증 환경이 부족하다는 이유로 Windows ARM을 낮은 지원 등급으로 분류하거나 릴리스에서 제외하지 않는다. 지원 방향과 각 릴리스에서 실제로 확인한 범위는 구분해 설명한다. 현재 배포 산출물은 [릴리스 가이드](../dev-guide/release.md)에 있다.

모바일은 별도 제품 원칙을 추후 새로 세운다. 이번 원칙의 지원·기능 배치 판단에 포함하지 않는다.

## 호환성과 버전 부여

버전 간 호환성 유지에 별도의 제품 기준을 두지 않는다. 기존 설정·API·플러그인의 호환성을 유지할지 바꿀지와 버전을 어떻게 올릴지는 개발자가 판단한다.

특정 구현에서 호환 형식이나 capability 협상을 사용하는 것은 허용한다. 이를 모든 버전에서 지켜야 하는 유예 기간이나 버전 번호별 호환성 의무로 확대하지 않는다. 에이전트가 수행하는 버전 증가·패키징 작업 절차는 [릴리스 가이드](../dev-guide/release.md)를 따른다.
