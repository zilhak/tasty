## 트리거

어떤 키·마우스 조작으로 화면을 여는지 쓴다.

## UI 요소 인벤토리

영역/요소 목록 (스펙 레벨). 각 요소가 무엇이고 무엇을 하나.
다른 기능으로 가는 요소는 그 문서 링크만 둔다 (예: 도구 버튼 → `../../tools-menu/`).

## 상태별 시각

로딩·빈 상태·오류 등 부모 문서의 상태를 화면에 어떻게 표시하는지 쓴다.

## 시각 소스
