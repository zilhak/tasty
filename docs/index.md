> **재정비 중**: docs 를 새 문서 모델에 맞춰 다시 쓰는 중이다. 옛 문서는 참고용으로 [`docs-old/`](../docs-old/) 에 보존되어 있으나 **현재 상태와 안 맞는 부분이 많다** (특히 화면기획 — claude design 도입 이후 변경됨). 새로 작성·검증된 문서만 아래에 등재한다.
