# Finite HTTP backend

This host-local executor is independent of WebViews and wire dispatch. Its module declaration, dependencies, host runtime and transport adapter are supplied by the integrating host. The module alone does not enable remote HTTP rendering.

A host injects a Tokio runtime handle and resource limits, validates actual attach/source ownership, then owns one Document per binding and document/source generation. The trusted entry URL fixes the logical HTTP origin. Same-origin requests are allowed; other origins require the existing client policy. Each redirect is returned unchanged for the native browser to process and for the next request to be checked again. HTTPS, CONNECT, upgrades, event streams and unsupported content encodings fail explicitly. There is no ambient proxy, cookie jar, automatic retry, redirect following or automatic decompression.

UploadBuilder accepts exact offsets and chunks of at most 48KiB, charges a shared payload quota and freezes a complete upload identity. Uploads are buffered up to the configured upload quota before a single network send. This is bounded multi-frame assembly, not streaming upload to the upstream. Upload, encoded response and decoded scan representations have separate limits. A document retains bounded request tombstones until close: a failed or released request ID cannot silently retry a POST. Completed requests reuse the same immutable StoredResponse and ResponseId without another request. Scan and render adapters must reuse these bytes; only explicit new request/document generations can start another operation.

Operation emits Head, optional AllowanceRequired, credit-limited encoded Chunk events, and Complete or Failed. Credit names the exact response and next encoded offset, at most 48KiB. Known bodies above decimal 100000 bytes wait before application body reads. Unknown bodies may retain bounded lookahead to discover byte100001 but do not deliver it before allowance. Exactly100000 at EOF completes without oversized consent. Browser, HTTP library and kernel read-ahead are separate from application delivery. The common adapter applies the document aggregate2000000-byte policy and must not count replayed response bytes twice.

Complete contains encoded bytes with their original representation headers and separately decoded gzip/deflate scan bytes, each with length and SHA256. Plain content shares one body allocation. Supplying decoded bytes to a browser requires the adapter to adjust Content-Encoding/Length; forwarding encoded bytes keeps those headers. Chunk events are provisional body transfer; the adapter must hold rendering until its required complete-body script scan and consent have finished. Duplicate header values retain their order within each name; global header-name ordering/casing is normalized by the HTTP library. No CORS/CSP/cookie/origin headers are weakened. Connection-local and nominated hop headers are removed; nominations of security/representation headers are rejected.

The global payload quota charges logical retained byte lengths, not exact resident memory: vector capacity, one queued frame, bounded pending HTTP frame, parser/header buffers and allocator overhead are additional bounded resources. Worker slots and document request capacity bound concurrent operations and metadata. Host code must also bound the number and lifetime of document owners. Runtime/network resources remain owned until worker completion; decoded work checks cancellation between reads. Network time bounds cumulative awaits and excludes consumer/consent waits; resource and caller cancellation bounds those waits. No child processes are spawned by this backend.

Drain terminal events or cancel before Operation::join. Dropping an operation, document, or a pending join future cancels without blocking the main loop. Host shutdown should cancel and asynchronously join operations before shutting down its injected runtime. The native adapter must fence late queued events using attach, source and document identities. Closing a document retires its cache; external body references remain quota-charged until released.

Native proxy authentication for CORS preflight and generation-scoped HTTP/Service Worker cache handling belong to the adapter. A proxy alone cannot observe synthetic/cached responses. This executor neither disables browser policies nor provides a client-network fallback. TLS and its native capability checks require a separate implementation.

The endpoint module authenticates SOCKS5 with a fresh session token before parsing HTTP, including OPTIONS. It rejects no-auth fallback, bounds negotiation frames/deadline and returns an authority without acknowledging the route. The native/common owner binds only loopback, validates live source/document ownership and capacity, prepares its response parser, then accepts the route. Dropping its future/stream cancels negotiation; no forwarding tunnel or global proxy setting is installed.
