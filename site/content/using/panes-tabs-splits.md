# 페인 · 탭 · 분할

이 페이지를 읽으면 화면을 나누고, 탭을 다루고, 서피스를 옮기거나 다른 종류로 바꾸고, 자주 쓰는 배치를 프리셋으로 저장하는 방법을 알게 됩니다. 용어는 [첫 화면 둘러보기](../getting-started/first-look.md)를 따릅니다.

단축키는 기본 프리셋(**Tasty**) 값입니다. `Alt` 는 macOS 에서 `Cmd`, `Ctrl` 은 `Control` 입니다.

## 두 단계 분할 — 먼저 고르기

| | 페인 분할 | 서피스 분할 |
|--|-----------|-------------|
| 나누는 것 | 워크스페이스 | 탭 하나의 안쪽 |
| 탭을 바꾸면 | 다른 페인은 그대로 | 분할 전체가 함께 바뀝니다 |
| 탭 스트립 | 페인마다 따로 | 탭 하나가 공유 |
| 좌우 / 상하 | `Alt+E` / `Alt+Shift+E` | `Alt+D` / `Alt+Shift+D` |
| 다음 / 이전 포커스 | `Ctrl+]` / `Ctrl+[` | `Alt+]` / `Alt+[` |
| 닫기 | `Ctrl+Shift+W` | `Alt+W` |

- 한쪽에 에이전트를 붙박이로 두고 다른 쪽에서 탭을 여럿 오가려면 **페인** 분할.
- 한 작업에 딸린 로그 · 에디터를 나란히 두고 탭째로 오가려면 **서피스** 분할.

새 칸의 터미널은 원래 칸의 작업 디렉터리에서 시작합니다(**설정** > **터미널** > **작업 디렉토리 상속**). 칸 사이 경계를 드래그하면 비율이 바뀝니다.

탭 스트립 오른쪽의 분할 아이콘은 그 페인을 좌우로 나눕니다. 다른 종류의 서피스로 나누려면 CLI 를 씁니다.

```sh
tasty split --level pane --target-pane 1 --direction horizontal
tasty split --level surface --target-surface 5 --type markdown --file notes.md
tasty split --level surface --target-surface 5 --type explorer --path ~/proj
```

## 탭

### 만들기 · 닫기

- `+` 버튼 또는 `Alt+T` — 새 터미널 탭.
- `+` 우클릭 — **프리셋으로 탭 생성...** <!-- en: Create tab from preset... --> / **프리셋으로 페인 생성...** <!-- en: Create pane from preset... -->.
- 탭 스트립 빈 곳 우클릭 — **새 터미널** <!-- en: New Terminal --> · **새 마크다운...** <!-- en: New Markdown... --> · **새 탐색기** <!-- en: New Explorer --> · **새 HTML...** <!-- en: New HTML... --> · **새 이미지** <!-- en: New Image -->. 종류별 설명은 [파일 열기](files.md).
- 탭의 `×`, 탭 우클릭 > **탭 닫기** <!-- en: Close Tab -->, 또는 `Ctrl+W`. 마지막 남은 탭은 닫히지 않습니다 — 대신 `Ctrl+W` 가 페인을 닫습니다.

```sh
tasty list panes
tasty new tab --pane 1 --cwd ~/proj
tasty new tab --pane 1 --type html --url https://example.com
tasty list tabs --pane 1
tasty close tab --tab 7
```

### 전환 · 순서

- 클릭, 또는 `Ctrl+1` ~ `Ctrl+9`, `Ctrl+0` (10 번째). `Ctrl` 을 누르고 있으면 탭에 번호가 뜹니다.
- `Ctrl+L` / `Ctrl+H` — 다음 / 이전 탭. **다음 탭** <!-- en: Next tab --> / **이전 탭** <!-- en: Previous tab --> 단축키는 OS 와 겹치지 않도록 기본값이 비어 있습니다.
- 드래그로 순서를 바꿉니다. 탭 우클릭 > **왼쪽으로 이동** <!-- en: Move Left --> / **오른쪽으로 이동** <!-- en: Move Right --> 도 됩니다.
- 탭이 넘치면 좌우 화살표가 생깁니다. 단축키로 전환하면 활성 탭이 보이도록 자동 스크롤합니다.

### 이름과 표시

탭 이름은 우선순위대로 정해집니다 — 직접 지정한 이름 > 프로그램이 설정한 창 제목 > 셸의 현재 디렉터리.

- 탭 우클릭 > **탭 이름 변경** <!-- en: Rename Tab --> 또는 `F2`. 지정하면 디렉터리를 옮겨도 바뀌지 않습니다.
- **녹색 점** — 셸이 아닌 프로그램이 출력을 내는 중. 프롬프트 대기 중이거나 프로그램이 멈춰 있으면 사라집니다.
- **노란 이름** — 프로그램이 입력을 기다립니다. **파란 이름** — 작업이 끝났습니다. 그 서피스를 클릭하면 원래 색으로 돌아옵니다.

탭 폭과 글자 크기는 **설정** > **외관** <!-- en: Appearance --> 의 **탭 너비** <!-- en: Tab width --> · **탭 폰트 크기** <!-- en: Tab font size -->.

### 재시작 후 보이지 않는 탭

레이아웃을 복원할 때 화면에 보이지 않는 탭의 셸은 바로 띄우지 않고 그 탭을 처음 열 때 시작합니다. `tasty list surfaces` 에는 `pty_ready: false` 로 나타나며, 열지 않고 미리 띄우려면 `tasty wake --surface <ID>`.

## 서피스 옮기기

살아 있는 서피스를 다른 탭 · 페인 · 워크스페이스로 옮깁니다. 터미널이면 실행 중인 프로그램과 스크롤백이 그대로 따라갑니다.

1. 옮길 서피스의 빈 곳을 우클릭 > **잘라내기** <!-- en: Cut -->.
2. 목적지 서피스의 빈 곳을 우클릭 > **여기로 이동** <!-- en: Move Here -->.

목적지 서피스는 닫히고 옮겨온 서피스가 그 자리를 차지합니다. 빈 터미널을 먼저 만들어 목적지로 삼으면 됩니다. 마우스를 잡는 프로그램(vim 등) 위에서는 `Shift+우클릭`.

## 종류 바꾸기

`Alt+'` 를 누르면 **서피스 타입 전환** <!-- en: Surface Type --> 팝업이 뜹니다. 현재 서피스를 그 자리에서 **터미널** <!-- en: Terminal --> · **탐색기** <!-- en: Explorer --> · **마크다운** <!-- en: Markdown --> · **HTML...** · **이미지** <!-- en: Image --> · **DAG** 로 바꿉니다. 방향키와 `Enter`, 또는 첫 글자로 고릅니다. 빈 서피스 가운데의 버튼도 같은 팝업입니다.

- 탐색기로 바꾸면 터미널의 현재 디렉터리를 루트로 엽니다.
- 마크다운 · HTML 은 파일 경로 · URL 을 묻습니다.
- 이전 내용은 사라집니다. 터미널 → 탐색기 → 터미널로 되돌려도 셸 세션은 새로 시작합니다.

**마크다운으로 전환** <!-- en: Convert to Markdown --> · **탐색기로 전환** <!-- en: Convert to Explorer --> 은 팝업 없이 바로 바꾸는 단축키로, 기본값이 비어 있습니다.

## 전체화면

알림 창 타이틀바의 전체화면 버튼(툴팁 **전체화면으로 보기** <!-- en: Show fullscreen -->)을 누르면 Tasty 창이 모니터를 덮고 알림 목록만 크게 보입니다. `Esc` 또는 오른쪽 위 종료 버튼으로 나옵니다. 나오면 창 크기와 터미널 격자가 진입 전 그대로입니다. 현재 이 무대에 올릴 수 있는 것은 알림 목록뿐입니다.

## 레이아웃 저장 — 프리셋

자주 쓰는 배치를 프리셋으로 저장해 두고 새 워크스페이스 · 탭 · 페인을 만들 때 꺼내 씁니다. 저장되는 것은 분할 구조와 각 칸의 종류 · 작업 디렉터리 · 시작 명령어 · 파일 경로 · URL 입니다.

### 저장

- 워크스페이스 — 사이드바 카드 우클릭 > **워크스페이스 프리셋으로 저장** <!-- en: Save as workspace preset -->.
- 탭 — 탭 우클릭 > **탭 프리셋으로 저장** <!-- en: Save as tab preset -->.
- 페인 — 탭 스트립 빈 곳 우클릭 > **페인 프리셋으로 저장** <!-- en: Save as pane preset -->.

파일은 `~/.tasty/presets/{workspace,tab,pane}/<이름>.toml` 에 생깁니다. 같은 이름이 있으면 `-2` 처럼 뒤에 번호가 붙습니다.

### 편집

사이드바 **도구** <!-- en: Tools --> > **프리셋** <!-- en: Presets --> 을 열면 **레이아웃 프리셋** <!-- en: Layout Presets --> 창이 뜹니다.

- 위쪽 탭으로 **워크스페이스** / **탭** / **페인** 을 고르고, 왼쪽 목록에서 프리셋을 고릅니다.
- 오른쪽에 구조 미리보기가 보입니다. 툴바의 **이름 변경** <!-- en: Rename --> · **복제** <!-- en: Duplicate --> · **삭제** <!-- en: Delete -->.
- **편집** <!-- en: Edit --> 을 누르면 미리보기 위에서 직접 고칩니다 — 칸을 클릭해 종류 · 작업 디렉터리 · 시작 명령어를 바꾸고, 칸 가장자리에 마우스를 올려 나타나는 띠를 클릭해 그쪽으로 나누고, 오른쪽 위 핸들로 칸을 지우고, `+` / `×` 로 탭을 더하고 뺍니다. 본체와 같은 분할 · 닫기 단축키도 동작합니다.
- 저장 버튼은 없습니다. 바꾸는 즉시 파일에 반영되고 **자동 저장됨** <!-- en: saved automatically --> 이 표시됩니다. **완료** <!-- en: Done --> 로 나옵니다.
- **새 프리셋** <!-- en: New preset --> 은 터미널 하나짜리 빈 프리셋을 만듭니다.

### 적용

- **새 워크스페이스** 버튼 우클릭 > **프리셋으로 새 워크스페이스 생성...** <!-- en: Create workspace from preset... -->.
- 탭 스트립 `+` 우클릭 > **프리셋으로 탭 생성...** / **프리셋으로 페인 생성...**.
- **워크스페이스 프리셋 적용** <!-- en: Apply workspace preset --> 등 단축키 세 개는 기본값이 비어 있습니다. 지정하면 선택 팝업이 뜹니다.

터미널 칸에 시작 명령어가 있으면 셸이 뜨자마자 한 줄 입력됩니다.

```sh
tasty preset list --kind workspace
tasty preset capture --kind workspace --source-id 2 --name dev
tasty preset apply --kind workspace --name dev
tasty preset apply --kind tab --name logs --target-pane 1
```

CLI 로 적용하면 포커스는 움직이지 않습니다. 재시작 시 자동 복원과 닫은 항목 복원은 [워크스페이스](workspaces.md#재시작-후-복원)에 있습니다.
