# 파일 열기

터미널 옆에서 README를 읽거나 이미지를 확인해 보세요. Tasty 안에서 탐색기, 마크다운, 이미지, HTML 화면을 열 수 있고, Git 보기로 변경 사항도 살펴볼 수 있습니다.

## 여는 방법

| 어디서 | 어떻게 |
|--------|--------|
| 사이드바 **도구** <!-- en: Tools --> > **파일 열기…** <!-- en: Open File… --> | Tasty 자체 파일 선택 창. 지금 보고 있는 터미널·탐색기의 폴더에서 열리고, 원격 워크스페이스에서는 원격 파일을 보여줍니다 |
| 파일을 윈도우 위로 드래그 | **여기에 드롭하여 열기** <!-- en: Drop to open --> 가 뜨면 놓습니다. 탐색기 칸 위에 놓으면 열지 않고 그 폴더로 복사합니다 ([끌어서 옮기기](#끌어서-옮기기)) |
| 탐색기 서피스 | 파일 더블클릭 |
| 터미널 | `Ctrl+클릭`, 또는 경로를 선택하고 우클릭 > **파일 열기** <!-- en: Open File --> ([터미널 다루기](terminal.md#링크와-경로-열기)) |
| 탭 스트립 빈 곳 우클릭 | **새 마크다운...** <!-- en: New Markdown... --> · **새 탐색기** <!-- en: New Explorer --> · **새 HTML...** <!-- en: New HTML... --> · **새 이미지** <!-- en: New Image --> |
| `Alt+'` | 현재 서피스를 다른 종류로 바꿉니다 ([종류 바꾸기](panes-tabs-splits.md#종류-바꾸기)) |
| CLI | `tasty new tab --pane 1 --type markdown --file README.md` 등 |

파일 확장자에 따라 어떤 서피스로 열지가 정해집니다 — `.md` 는 마크다운, 이미지 파일은 이미지, `.html` 과 `.svg` 는 HTML, 폴더는 탐색기. 어느 것으로 열지 정해지지 않으면 **다음으로 열기…** <!-- en: Open file with… --> 창이 떠서 고르게 하고, 고른 것은 **최근 선택** <!-- en: Recent --> 에 남습니다. 확장자 매핑과 핸들러는 **설정** > **핸들러** <!-- en: Handler --> 탭에서 바꿉니다.

**다음으로 열기…** 창에는 파일 경로, 인식한 형식, 선택할 수 있는 핸들러가 표시됩니다. 핸들러마다 아이콘, 이름, 출처(**기본 제공** <!-- en: built-in --> · **직접 등록** <!-- en: you --> · **plugin**)가 보입니다.

**최근 선택**에는 전에 쓴 핸들러와 사용 시점이 표시됩니다. 방금 · 몇 분 전 · 몇 시간 전 · 어제 · 며칠 전으로 표시하다가, 일주일이 넘으면 `2026-09-13`처럼 날짜로 바뀝니다. 창을 열어 둔 채 자정을 넘겨도 표시가 갱신됩니다.

한 번 누르면 핸들러를 선택하고, 두 번 누르면 파일을 엽니다. 이 선택은 **이번 한 번만** 적용되며 파일 형식의 기본 핸들러로 등록되지 않습니다. 같은 파일을 다시 열 때 선택 창이 나올 수 있습니다. 기본 핸들러는 **설정** > **핸들러**에서 정하세요. 창은 `Esc`나 **취소** <!-- en: Cancel --> 로 닫습니다.

위의 방법으로 직접 연 파일은 새 탭으로 열리면서 **그 탭으로 바뀝니다.** AI 에이전트가 대신 열어 줄 때는 탭만 늘고 보고 있던 탭은 그대로 남습니다 — 작업하던 화면이 갑자기 바뀌지 않게 하기 위해서입니다.

열기를 요청한 서피스가 지정되어 있으면, 기다리는 동안 다른 윈도우로 이동해도 원래 서피스의 페인에 새 탭으로 열립니다. 다른 페인을 보고 있을 때 탐색기에서 파일을 열어도 탐색기가 있는 페인에 열립니다. 원래 서피스를 닫으면 다른 윈도우에 대신 열지 않습니다.

파일로 연 서피스는 다른 서피스와 똑같이 분할 · 이동 · 닫기 · 재시작 복원의 대상입니다. 탭 이름은 파일명이 됩니다.

파일 선택 창은 맨 위 한 줄(제목과 ✕가 있는 줄)을 끌어 옮깁니다. ✕, **취소** <!-- en: Cancel -->, `Esc` 중 하나로 닫으면 아무 파일도 열지 않습니다.

파일 선택 창의 목록 위에는 이름·크기·수정일 열 이름이 있고, 고른 행은 왼쪽 끝에 색 막대가 붙습니다. 긴 파일명은 `…`로 줄여 크기·수정일과 겹치지 않게 표시합니다. 줄여 표시해도 선택하거나 여는 파일은 바뀌지 않습니다.

파일 종류를 정해 두고 열었다면(예: 단축키 가져오기는 `.toml` 만) 이름 칸 오른쪽에 `*.toml` 처럼 보여 줄 확장자를 적은 칸이 있습니다. 확장자가 많으면 끝이 `…` 로 줄고, 마우스를 올리면 전체 목록이 보입니다. 이 칸은 안내일 뿐 눌러서 바꿀 수는 없습니다. 종류를 정하지 않고 열었다면 이 칸이 없습니다.

목록에서 한 번 누르면 파일이든 폴더든 그 줄이 선택되고, 두 번 누르면 폴더는 그 안으로 들어가고 파일은 열립니다. 폴더를 선택한 채 **열기** <!-- en: Open --> 를 누르면 그 폴더로 들어갑니다 — 키보드로 내려가는 길입니다. 저장할 위치를 고를 때는 폴더가 저장 대상이 될 수 없으므로, 폴더를 선택하면 이름 칸은 그대로 두고 아래에 그 사실을 알리는 회색 줄이 한 줄 뜹니다. 저장할 때 파일을 두 번 눌렀을 때는 이름만 채워지고 저장되지는 않습니다 — 덮어쓰기 경고를 읽을 기회를 남기기 위해서입니다.

## 탐색기

Tasty 안에 들어 있는 파일 관리자입니다. 터미널에서 `Alt+'` > **탐색기** 로 바꾸면 그 터미널의 현재 디렉터리를 루트로 엽니다. `tasty new tab --pane 1 --type explorer --path ~/proj` 로도 엽니다.

### 화면

- **왼쪽** — **파일** <!-- en: Files --> 트리(루트 고정)와 그 아래 **즐겨찾기** <!-- en: Favorites -->.
- **위쪽** — **뒤로** <!-- en: Back --> · **앞으로** <!-- en: Forward --> · **위로** <!-- en: Up --> · **새로고침** <!-- en: Refresh -->, 주소창, **새 폴더** <!-- en: New folder --> · **새 파일** <!-- en: New file --> 버튼과 **찾기** <!-- en: Find --> · **미리보기 패널** <!-- en: Preview panel --> 토글, 보기 전환(**그리드** <!-- en: Grid --> · **목록** <!-- en: List --> · **상세** <!-- en: Detail -->). 탐색기 칸이 440px 보다 좁으면 명령 버튼이 **더 보기** <!-- en: More --> (`…`) 하나로 접히고, 누르면 같은 명령이 메뉴로 나옵니다. 메뉴의 찾기·미리보기 줄은 누르면 할 일을 씁니다(**찾기** ↔ **찾기 닫기** <!-- en: Close find -->, **미리보기 표시** <!-- en: Show preview --> ↔ **미리보기 숨기기** <!-- en: Hide preview -->).
- **오른쪽** — 현재 폴더의 항목. 그리드 보기에서는 로컬 이미지 파일(1 MB 이하)이 아이콘 대신 작은 썸네일로 보입니다. 맨 위 `..` 로 상위 폴더에 갑니다. 상세 보기에서는 **이름** · **크기** · **수정일** · **형식** 열 제목을 클릭해 정렬합니다.
- 서피스 안에 **새 탭** <!-- en: New tab --> 을 여러 개 두고 폴더를 따로따로 볼 수 있습니다. 페인의 탭과는 별개입니다.

탐색기가 든 배치를 프리셋으로 저장했다가 적용하면, 탐색기 안의 탭마다 보던 폴더와 보기·정렬이 그대로 열리고, 페인 탭 제목은 활성 탭이 연 폴더(루트) 이름입니다. 프리셋 편집에서 작업 디렉터리를 정해 두었으면 저장한 탭 대신 그 폴더 하나로 엽니다. 저장한 폴더가 지금은 없으면 그 탭에 읽기 오류 안내가 나옵니다.

분할선을 끌어 탐색기 칸을 줄이면 툴바·상태줄과 목록 두어 줄이 남는 높이(180px)에서 멈춥니다. 탐색기 칸을 나누거나 탐색기를 새로 나눠 만들 때도 탐색기 칸이 180px 을 지키도록 분할선이 한쪽으로 옮겨집니다. 다른 종류의 칸은 남는 높이를 받지만, 탭 줄과 한 줄이 들어가는 높이(56px)보다 얇게 나뉘지는 않습니다. 탐색기 칸끼리 180px 을 지킬 공간이 없거나 다른 칸이 56px 을 지킬 공간이 없으면 분할하지 않고, 분할 메뉴·단축키에서는 "이 패널을 나눌 공간이 부족합니다" 알림이 잠깐 뜨며 `tasty split` 은 그 이유를 오류로 알려 줍니다. 칸이 낮아 왼쪽 사이드바가 240px 보다 낮아지면 즐겨찾기는 숨고 파일 트리만 보입니다. 윈도우 크기를 줄이면 이 높이 아래로도 내려갈 수 있습니다. 내용 영역이 120px 보다 낮으면 빈 폴더·권한 거부·읽기 오류 안내가 아이콘 · 제목 · 버튼 한 줄로 바뀌고, 자세한 이유는 제목에 마우스를 올리면 보입니다.

폴더를 읽지 못하면(경로가 사라졌거나 폴더가 아니거나 원격 읽기가 실패한 경우) 목록 자리에 **이 폴더를 읽을 수 없습니다** <!-- en: Can't read this folder --> 와 운영체제가 알려 준 이유가 나옵니다. **다시 시도** <!-- en: Retry --> 는 같은 폴더를 다시 읽고, **상위 폴더로** <!-- en: Go up --> 는 한 단계 위 폴더로 갑니다. 위 폴더도 함께 사라졌으면 남아 있는 가장 가까운 위 폴더로 갑니다. 권한이 없을 때는 따로 **접근 거부** <!-- en: Permission denied --> 가 나옵니다.

탐색기에서 붙여넣기 · 이름 변경 · 휴지통으로 보내기를 하면, 바뀐 폴더를 보고 있는 다른 탐색기도 (다른 윈도우여도) 목록과 왼쪽 트리를 다시 읽습니다. 지금 보던 폴더가 지워졌거나 이름이 바뀌었으면 그 자리에서 읽기 오류 안내가 나오고, 다른 폴더로 저절로 옮겨 가지는 않습니다. 다른 프로그램이 폴더에 항목을 만들거나 지우거나 이름을 바꾸면, 지금 쓰고 있는 Tasty 윈도우에서 포커스가 있는 탭의 탐색기가 2 초 안에 알아채 목록과 펼쳐 둔 트리를 다시 읽습니다. 이때 선택과 스크롤 위치는 그대로입니다. 다른 탭에 있던 탐색기나 다른 앱을 쓰는 동안의 탐색기는 그 탭이나 Tasty 윈도우로 돌아오는 순간 확인합니다. 파일 내용이나 크기만 바뀐 경우와 원격(attach) 탐색기는 자동으로 반영되지 않으니 **새로고침** (`F5`) 을 누르세요. 새로고침은 펼쳐 둔 트리도 함께 다시 읽습니다. 다시 읽었을 때 선택해 둔 항목이 사라졌으면 그 항목은 선택에서도 빠집니다.

주소창을 클릭하면 경로를 직접 입력할 수 있고, 최근 방문한 폴더가 자동완성으로 뜹니다. `Enter` 또는 **이동** <!-- en: Go --> 으로 갑니다. 왼쪽 트리는 루트에 고정되지만 오른쪽 목록은 어디로든 갈 수 있습니다.

- 상대 경로는 지금 보고 있는 폴더 기준입니다. `..` 은 한 단계 위입니다.
- `~` 와 `~/폴더` 는 홈 폴더 아래입니다.
- Windows 에서는 `C:` 처럼 드라이브만 적으면 그 드라이브의 맨 위로 가고, `\\서버\공유` 같은 네트워크 경로도 쓸 수 있습니다.
- 폴더가 아니거나 없는 경로, 대상이 사라진 링크를 입력하면 이동하지 않고 이유를 알림으로 보여 줍니다.
- 원격 워크스페이스의 탐색기에서는 입력한 경로를 원격 컴퓨터에서 찾습니다. 로컬에 없는 폴더도 원격에 있으면 열리고, 원격에서 읽지 못하면 목록 자리에 이유가 나옵니다. `~` 는 원격 컴퓨터의 홈 폴더이고, `.` 과 `..` 도 원격 경로 기준으로 풉니다. 연결한 직후 원격 홈을 아직 알아내지 못했으면 `~` 대신 원격 경로를 전부 적으라고 알려 줍니다.

### 새 폴더 · 새 파일

툴바의 **새 폴더** · **새 파일**, 빈 곳 우클릭 메뉴, 폴더 우클릭 메뉴(그 폴더 안에 만듭니다)에서 시작합니다. 목록 맨 위에 이름 입력 줄이 열리고 "새 폴더" 는 이름 전체가, "제목 없음.txt" 는 확장자 앞까지 선택되어 있습니다. 같은 이름이 있으면 "새 폴더 2" 처럼 번호가 붙은 이름으로 시작합니다.

- `Enter` 로 만들고, `Esc` 로 취소합니다. 취소하면 디스크에는 아무것도 생기지 않습니다.
- 입력 줄 밖을 누르면 이름이 올바를 때는 만들고, 비었거나 잘못됐으면 취소합니다.
- 이름이 비었거나(공백만 있는 이름 포함) 쓸 수 없는 글자(`/`, Windows 에서는 `\ : * ? " < > |` 도)가 들어 있거나 이름이 공백으로 시작하거나 끝나거나 Windows 가 예약한 이름(`CON`, `NUL` 등)이거나 Windows 에서 이름 끝이 점이면 입력 칸 아래에 이유가 바로 나옵니다. 이미 있는 이름은 `Enter` 를 누를 때 알려 주며, 입력 줄은 연 채로 글자를 그대로 둡니다. 덮어쓰지 않습니다.
- 만든 항목은 정렬된 자리로 가서 선택됩니다. 그 사이 다른 폴더로 옮겨 갔다면 선택은 바뀌지 않습니다.
- 쓸 수 없는 폴더에서는 두 버튼이 흐려지고, 마우스를 올리면 **이 폴더에 쓸 수 없습니다** <!-- en: Can't write to this folder --> 가 보입니다. 원격 워크스페이스의 탐색기에는 이 버튼과 메뉴 항목이 없습니다.

설정 > 단축키 > **탐색기** <!-- en: Explorer --> 에서 **새 폴더** · **새 파일** 에 키를 지정할 수 있습니다. 기본 키는 없습니다.

### 찾기 · 하위 폴더 검색

툴바의 **찾기** 토글(칸이 좁으면 **더 보기** 메뉴)이나 탐색기에 포커스가 있을 때의 `Ctrl+F` 로 툴바 아래에 찾기 줄을 엽니다. `Ctrl+F` 는 터미널 검색과 같은 단축키이고, 탐색기에서는 이 찾기 줄을 엽니다.

- 입력하는 즉시 지금 폴더에서 이름에 그 글자가 들어 있는 항목만 남습니다. 대소문자는 구분하지 않고, 맞는 부분은 강조색으로 보입니다. 오른쪽에 "2 / 6" 처럼 보이는 수와 전체 수가 나옵니다. 맞는 이름이 없으면 목록 자리에 "“…”와(과) 맞는 이름이 없습니다" 가 보입니다. 위 폴더로 가는 `..` 줄은 거르는 동안에도 남습니다.
- 걸러져 안 보이게 된 항목은 선택에서 빠집니다. 전체 선택도 보이는 항목만 고릅니다.
- **하위 폴더** <!-- en: Subfolders --> 를 켜면 지금 폴더 아래 전체에서 찾습니다. 찾는 동안 결과가 들어오는 대로 채워지고 **중지** <!-- en: Stop --> 로 멈출 수 있습니다(찾은 것은 남습니다). 상세 보기에서는 종류 대신 **폴더** <!-- en: Folder --> 열에 지금 폴더 기준 위치가 보이고, 목록·그리드 보기에서는 항목에 마우스를 올리면 보입니다. 결과 하나를 고르면 아래 상태줄에도 위치가 나옵니다. 읽을 수 없는 폴더는 건너뛰고 "폴더 1개 건너뜀" 처럼 알려 주며, 마우스를 올리면 그 폴더들이 보입니다. 결과가 5,000 개에 닿으면 검색을 멈추고 "5,000개 이상 찾음 · 중지됨" 을 보입니다. 찾은 결과는 남으며, 검색어를 더 입력하면 범위를 좁힐 수 있습니다. 폴더 링크 안으로는 들어가지 않습니다.
- 찾기 칸에서 `Esc` 를 한 번 누르면 글자를 지우고, 한 번 더 누르면 찾기 줄을 닫습니다. ×, 다른 폴더로 이동(뒤로·위로·주소창·폴더 열기)으로도 닫힙니다.
- 찾기 칸에 글자를 입력하는 동안에는 글자를 쳐서 찾기와 탐색기 단축키가 동작하지 않습니다.
- 원격 워크스페이스의 탐색기는 지금 폴더 거르기만 하고 하위 폴더 검색은 없습니다.

### 미리보기 패널

툴바의 **미리보기 패널** 버튼을 누르면 목록 오른쪽에 패널이 열리고, 선택한 파일 하나를 보여 줍니다. 텍스트 파일은 앞부분(64 KB)을 고정폭 글꼴로, 이미지는 패널에 맞춰(원래 크기보다 키우지 않고) 보여 줍니다. 그 밖의 형식이나 폴더는 **이 파일 형식은 미리 볼 수 없습니다** <!-- en: No preview for this file type -->, 1 MB 보다 큰 파일과 한 변이 16384 픽셀을 넘는 등 펼치기에 너무 큰 이미지는 **너무 커서 미리 볼 수 없습니다** <!-- en: Too large to preview --> 가 나옵니다. 이미지가 픽셀 상한을 넘으면 그 이미지의 실제 크기도 함께 보입니다. 파일을 여러 개 고르면 몇 개를 골랐는지 보이고, 하나만 고르라고 안내합니다. 패널 왼쪽 경계를 끌어 너비를 200~460px 사이로 바꿀 수 있습니다. 켜 둔 상태와 너비는 탐색기마다 기억되어 Tasty 를 다시 열어도 그대로이고, 프리셋으로 저장해도 따라갑니다. 탐색기 칸이 좁아 목록과 함께 둘 수 없으면 버튼은 켜진 채 패널만 잠시 숨습니다. 원격 워크스페이스의 탐색기에서는 미리 볼 수 없습니다.

### 속성

우클릭 메뉴 맨 아래 **속성** <!-- en: Properties --> 을 고르면 탐색기 칸 안에 팝업이 뜹니다. 파일은 형식 · 크기(바이트 포함) · 수정일 · 만든 날짜 · 위치 · 권한을, 링크는 가리키는 대상을 보여 주고, 위치와 링크 대상은 옆의 복사 버튼으로 복사합니다. 폴더는 하위 항목 수와 크기를 뒤에서 세는 동안 진행 표시가 돌고, 팝업을 닫으면 세기를 멈춥니다. 여러 항목을 고르면 개수 · 종류 · 전체 크기 · 공통 위치를, 빈 곳을 우클릭하면 지금 폴더를 보여 줍니다. 원격 탐색기에서는 목록에 있는 형식 · 크기 · 수정일 · 위치만 보입니다. 정보를 읽지 못하면 이유와 함께 **다시 시도** <!-- en: Retry --> 버튼이 나옵니다.

### 단축키 (탐색기에 포커스가 있을 때)

| 하는 일 | 단축키 |
|---------|--------|
| 새로고침 | `F5` |
| 상위 폴더로 | `Alt+↑` |
| 전체 선택 | `Ctrl+A` · `Alt+A` |
| 경로 복사 | `Alt+Shift+C` |
| 찾기 | `Ctrl+F` · `Alt+F` |
| 복사 / 잘라내기 / 붙여넣기 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` (터미널과 같은 바인딩) |
| 미리보기 패널 켜기·끄기 · 속성 | 기본값 없음 — **설정** > **단축키** > **탐색기** 에서 지정 |

클릭으로 선택, `Ctrl+클릭` 으로 추가, `Shift+클릭` 으로 범위 선택. `Shift+클릭` 은 마지막으로 클릭한 항목부터 누른 항목까지를 고르고, `Ctrl+Shift+클릭` 은 지금 선택을 둔 채 그 범위를 더합니다. macOS 에서는 `Ctrl` 대신 `Cmd` 를 씁니다.

### 글자를 쳐서 찾기

목록에 포커스가 있을 때 파일 이름의 첫 글자를 입력하면 그 글자로 시작하는 항목이 선택되고 그 자리로 스크롤됩니다. 그리드·목록·상세 어느 보기에서나 같습니다. 같은 글자를 이어서 누르면 후보를 하나씩 넘어가고, 마지막 다음에는 처음으로 돌아갑니다. 다른 글자를 이어서 입력하면 `co`, `con` 처럼 앞글자 검색이 됩니다. 대소문자는 구분하지 않으며, 1 초쯤 쉬었다가 입력하면 새 검색으로 시작합니다. 해당하는 이름이 없으면 선택은 그대로 남습니다.

주소창을 편집 중이거나 팝업이 떠 있을 때는 입력한 글자가 그쪽으로 갑니다. 탐색기를 여러 개 띄워 두었다면 지금 포커스가 있는 하나만 움직입니다.

수식 키 없이 글자 하나에 단축키를 직접 지정해 두었다면 그 글자는 단축키로만 동작하고 이 기능에는 쓰이지 않습니다. 기본 설정에는 그런 단축키가 없습니다.

### 우클릭 메뉴

이름을 바꿀 때 같은 이름의 항목이 있으면 덮어쓰지 않고 실패를 알립니다. 복사할 때 심볼릭 링크는 링크로 보존하며, 실제로 같은 폴더이거나 그 하위인 경로에는 폴더를 붙여넣을 수 없습니다. 파일 작업이 실패하면 알림에 오류가 표시됩니다.

폴더를 가리키는 링크는 폴더처럼 열리고 주소창에는 링크의 경로가 남습니다. 링크의 이름 변경·휴지통 이동은 링크만 다루고 가리키는 폴더는 그대로 둡니다. 가리키는 대상이 사라진 링크를 열면 대상이 없다는 알림이 나옵니다.

- **새 폴더** <!-- en: New folder --> · **새 파일** <!-- en: New file --> — 빈 곳 메뉴의 맨 앞, 폴더 메뉴의 파일 조작 묶음에 있습니다. 위 "새 폴더 · 새 파일" 을 보세요.
- **경로 복사** <!-- en: Copy Path --> — 여러 개면 줄바꿈으로 이어 붙입니다.
- **복사** <!-- en: Copy --> · **잘라내기** <!-- en: Cut --> · **붙여넣기** <!-- en: Paste --> · **붙여넣기 (안으로)** <!-- en: Paste (into) --> — 같은 이름이 있으면 어떻게 할지 묻습니다 ([진행과 결과](#진행과-결과)).
- **휴지통으로 이동** <!-- en: Move to Trash --> — 확인 없이 OS 휴지통으로 보냅니다. 되돌리려면 휴지통에서. 그 드라이브에 휴지통이 없으면 아무것도 지우지 않고 알려 줍니다.
- **이름 변경** <!-- en: Rename -->. 새 이름에도 새 폴더·새 파일과 같은 규칙(빈 이름, 쓸 수 없는 글자, 앞뒤 공백, 예약 이름)이 적용되고, 맞지 않으면 입력 칸 아래에 이유가 나오며 저장되지 않습니다.
- **시스템에서 열기** <!-- en: Open in System --> — OS 파일 관리자로 폴더를 엽니다.
- **새 탭으로 열기** <!-- en: Open in New Tab --> — 그 폴더를 루트로 하는 탐색기 탭을 페인에 하나 더 엽니다.
- **이 폴더로 루트 설정** <!-- en: Set as Root --> — 왼쪽 트리의 루트를 옮깁니다.
- **즐겨찾기에 추가** <!-- en: Add to Favorites --> — 이름을 붙여 왼쪽 아래 목록에 둡니다. 즐겨찾기는 모든 탐색기가 공유하며 `~/.tasty/explorer-favorites.toml` 에 저장됩니다. 다른 윈도우에서 추가하거나 지운 즐겨찾기도 바로 반영됩니다.
- **속성** <!-- en: Properties --> — 위 [속성](#속성) 팝업을 엽니다. 원격 탐색기에서도 나옵니다.

마지막으로 고른 보기 방식은 기억되어 새 탐색기에도 적용됩니다. 탐색기 폰트는 **설정** > **외관** <!-- en: Appearance --> 의 **탐색기** <!-- en: Explorer --> 항목에서 따로 지정합니다. 원격 워크스페이스의 탐색기에서는 파일을 바꾸는 항목이 나오지 않습니다. 원격 탐색기에서 복사한 항목은 로컬 탐색기에 붙여넣을 수 없습니다. 붙여넣기 메뉴가 나오지 않고, 단축키로 붙여넣으면 안내만 나옵니다. 경로가 같은 로컬 파일을 대신 복사하지 않습니다. 마크다운 파일을 더블클릭하면 원격 컴퓨터에 그 파일의 탭이 열리고, 기본 핸들러를 원격에서 쓸 수 없으면 원격에서 쓸 수 있는 핸들러만 골라 보여 주고, 그런 핸들러가 없는 형식이면 안내만 나옵니다.

### 끌어서 옮기기

항목을 끌어 폴더 줄·폴더 칸, 왼쪽 트리의 폴더, 즐겨찾기에 놓으면 그 폴더로 옮깁니다. 파일 위나 빈 곳에 놓으면 그 탐색기가 보고 있는 폴더로 갑니다. 옆에 띄운 다른 탐색기로 끌어도 됩니다.

- 같은 디스크면 **이동**, 다른 디스크면 **복사**합니다. `Ctrl` (macOS `Option`) 을 누른 채 놓으면 반대로 합니다. 이 키는 **설정** > **단축키** > **일반** 맨 아래의 **탐색기 드래그 전환 키** <!-- en: Explorer drag flip modifier --> 에서 바꿉니다(`config.toml` 의 `[keybindings]` `explorer_drag_flip_modifier` 와 같은 값입니다).
- 끄는 동안 포인터 옆 표시가 **(폴더)(으)로 이동** <!-- en: Move to --> · **(폴더)(으)로 복사** <!-- en: Copy to --> 처럼 무엇을 할지 미리 알려 줍니다. 놓을 수 없는 곳이면 **놓을 수 없음** <!-- en: Can't drop --> 과 이유(자기 안으로, 이미 그 폴더에 있음, 원격 폴더, 쓰기 권한 없음)가 나옵니다.
- 닫힌 트리 폴더 위에 잠시 머물면 펼쳐집니다. `Esc` 를 누르면 끌기를 취소합니다.
- 운영체제의 파일 관리자에서 탐색기 칸으로 끌어 온 파일은 그 폴더로 **복사**합니다(이동하지 않습니다). 원격 탐색기에는 놓을 수 없습니다. Linux(X11) 에서는 끄는 동안 칸 표시 대신 윈도우 전체 안내가 보이지만, 탐색기 칸 위에 놓으면 똑같이 복사됩니다.

### 진행과 결과

붙여넣기·끌어 놓기·휴지통 보내기는 한 번에 하나씩 차례로 처리합니다. 작업을 시작한 탐색기 아래 상태줄에 진행 막대, 지금 다루는 파일, 크기가 나오고, **×** 로 멈춥니다. 멈추면 끝난 항목은 그대로 두고 남은 항목은 하지 않습니다. 기다리는 작업이 있으면 **+1 대기** <!-- en: +1 queued --> 표시가 붙고, 누르면 목록이 열려 기다리는 작업을 뺄 수 있습니다. 기다리는 작업이 너무 많거나 한 번에 고른 항목이 너무 많으면 작업을 받지 않고 그 탐색기에 경고 카드로 알립니다. 대기열이 찬 경우에는 카드의 **대기열 보기** <!-- en: Show queue --> 로 목록을 열 수 있습니다.

같은 이름이 이미 있으면 그 탐색기에 포커스가 있을 때 묻는 팝업이 뜹니다. 다른 곳을 보고 있었다면 상태줄의 **보기** <!-- en: Show --> 를 누르세요.

- **둘 다 유지** <!-- en: Keep both --> (`Enter`) — 기본값입니다. 새 항목에 `(copy)` 를 붙여 둡니다. 기존 항목은 바뀌지 않습니다.
- **건너뛰기** <!-- en: Skip --> · **바꾸기** <!-- en: Replace --> (파일만) · **나머지 취소** <!-- en: Cancel the rest --> (`Esc`).
- 같은 이름의 폴더는 합치지 않습니다. 폴더에는 건너뛰기와 둘 다 유지만 고를 수 있습니다.
- 충돌이 더 남았으면 **남은 충돌 n개에도 적용** <!-- en: Do this for the other conflicts --> 을 켜 한 번에 답합니다.

끝나면 탐색기 오른쪽 아래에 결과 카드가 뜹니다. 모두 끝난 카드는 잠시 뒤 사라지고, 실패하거나 건너뛴 항목이 있는 카드는 닫을 때까지 남아 그 경로를 보여 줍니다.

- **다시 시도** <!-- en: Retry --> — 실패하거나 건너뛴 항목만 다시 합니다. 원본이 남은 이동 항목은 원본 지우기만 다시 합니다.
- **경로 복사** <!-- en: Copy paths --> — 카드의 경로를 클립보드에 담습니다.
- **되돌리기** <!-- en: Undo --> — 모두 끝난 복사·이동에서 카드가 보이는 동안 나옵니다. 옮긴 항목은 제자리로 돌리고(그 자리에 다른 항목이 생겼으면 그대로 둡니다), 복사본은 휴지통으로 보냅니다. 복사 뒤 고친 복사본은 남겨 둡니다. 바꾸기로 덮어쓴 파일은 되돌리지 못합니다.

다른 디스크로 옮길 때 원본을 다 지우지 못하면(예: 쓰기 권한이 없는 하위 폴더) 원본이 전부 또는 일부 남았다는 경고 카드가 닫을 때까지 남습니다. 이때 복사본이 온전한 자료이므로 되돌리기는 나오지 않습니다. 막던 원인을 푼 뒤 **다시 시도** 를 누르면 남은 원본만 지웁니다. 그사이 복사본이 없어졌거나 다른 것으로 바뀌었으면, 또는 원본 파일을 고쳤으면 원본을 지우지 않고 그 이유를 보여 줍니다. 복사본 경로가 링크 등으로 원본과 같은 파일을 가리키면 지우지 않습니다. 폴더는 복사본에 내용까지 똑같이 있는 항목만 지우고(큰 파일은 비교하는 동안 진행이 보이고 취소할 수 있습니다. 취소하면 아직 남은 원본만 경고 카드에 다시 남아 나중에 다시 시도할 수 있습니다), 옮긴 뒤 원본 폴더에 넣거나 고친 항목은 남긴 뒤 그 개수를 보여 줍니다.

## 마크다운

`.md` 파일을 렌더해 보여줍니다. 파일이 바뀌면 1 초 안에 자동으로 다시 그립니다.

- 표 · 체크박스 · 각주 · 코드 강조 · `mermaid` 다이어그램 · `$…$` 수식 · `> [!NOTE]` 콜아웃(Obsidian 식 `[!tip]-` 접기 포함) · 맨 위 frontmatter 숨김.
- 제목이 있으면 본문 위에 접을 수 있는 **목차** <!-- en: Table of contents --> 가 붙습니다. 항목을 누르면 보고 있던 문서 그대로 그 제목 자리로 내려갑니다 — 같은 항목을 다시 눌러도 다시 이동합니다.
- 코드 블록에 마우스를 올리면 **코드 복사** <!-- en: Copy code --> 버튼.
- 문서에 포커스가 있을 때 `Ctrl+F` (macOS `Cmd+F`) — **문서 내 검색** <!-- en: Find in document -->.
- 맨 위 주소창에 다른 파일 경로를 입력해 이동합니다. 최근 연 파일이 자동완성으로 뜹니다. 같은 Tasty 인스턴스의 다른 윈도우에서 연 파일도 최신순으로 최대 10개까지 함께 보입니다.
- 문서 안의 링크 — 다른 마크다운 · 파일은 같은 페인의 새 탭으로 열리고 Linux 에서는 그 탭으로 바로 넘어가며(macOS 에서는 새 탭이 뒤에 붙기만 합니다), `http(s)://` 는 브라우저로 갑니다. 상대 경로는 그 문서가 있는 폴더 기준입니다. 열 수 있는 핸들러가 없는 파일이면 **다음으로 열기…** 창이 떠서 고르게 합니다(원격 워크스페이스에서는 원격에 열 수 있는 핸들러만 보이고, 하나도 없으면 알림이 뜹니다). `#제목` 처럼 같은 문서 안을 가리키는 링크와 각주 번호 · 되돌아가기 화살표는 그 자리로 이동만 합니다.
- 1MB 를 넘는 파일은 **큰 파일을 열까요?** <!-- en: Open large file? --> 로 한 번 묻습니다. 이 확인 팝업은 그 마크다운 서피스 가운데에 뜹니다. 서피스가 팝업보다 좁으면 윈도우 가운데에 뜹니다. 작게 열었던 파일이 나중에 1MB 를 넘게 커져도 다시 읽기 전에 같은 확인을 띄우며, 답할 때까지 이전 내용이 그대로 보입니다. 취소하면 본문 자리에 **1MB를 넘는 파일이라 아직 읽지 않았습니다** <!-- en: This file is larger than 1 MB and has not been loaded --> 가 보입니다. 그 아래 **파일 열기…** <!-- en: Open file… --> 버튼을 누르면 같은 확인을 다시 띄웁니다. 취소한 파일은 바뀌어도 자동으로 읽지 않으며, `tasty markdown reload --surface <ID>` 로도 다시 물을 수 있습니다. **열기** 를 고른 파일은 그 뒤로 묻지 않습니다.

**새 마크다운...** 이나 `Alt+'` > **마크다운** 은 **마크다운 파일 열기** <!-- en: Open Markdown File --> 창을 띄웁니다. 경로를 입력하거나 **찾아보기…** <!-- en: Browse… --> 로 고릅니다. 찾아보기는 지금 보고 있는 터미널의 현재 폴더에서 시작하고, 입력한 상대 경로도 그 폴더 기준으로 엽니다. 이 팝업은 그 서피스 영역 가운데에 뜨고, 다른 워크스페이스나 탭으로 옮기면 잠시 숨었다가 돌아오면 입력하던 그대로 다시 보입니다. 찾아보기로 연 파일 선택 창도 함께 숨고 돌아오며, 고르던 파일과 탐색 중인 폴더를 유지합니다. 숨은 동안에는 다른 화면의 클릭과 키보드 입력을 막지 않습니다.

```sh
tasty markdown recent
tasty markdown reload --surface 5
```

## 이미지

PNG · JPEG 등을 보고, 간단히 그립니다. **새 이미지** 는 빈 캔버스로 시작합니다. 이미지를 연 채로 만들어도 원래 파일과는 별개라, **저장** 하면 저장할 경로를 묻습니다. 새 경로로 저장하면 탭 이름이 그 파일 이름으로 바뀌고, 다시 시작해도 그 파일이 열립니다. 파일이 밖에서 바뀌면 1 초 안에 자동으로 다시 읽습니다 — 다만 **편집 중일 때는 미뤘다가** 편집을 끝낼 때 반영합니다(그리는 중에 밑그림이 바뀌지 않도록).

- 툴바 — **이전 이미지** <!-- en: Previous image --> / **다음 이미지** <!-- en: Next image --> (같은 폴더 안, 넘어가면 탭 이름도 그 파일로 바뀝니다. 편집 중에는 넘어가지 않으니 먼저 저장하거나 취소합니다 — `tasty image next`·`prev` 도 이때는 오류로 끝납니다), **새로고침** <!-- en: Refresh -->, **편집** <!-- en: Edit -->, **새 이미지** <!-- en: New image -->, 확대 **맞춤** <!-- en: Fit --> / `+` / `-`.
- **편집** 을 누르면 **굵기** <!-- en: Brush --> · **색상** <!-- en: Color --> 을 고르고 위에 그립니다. `Ctrl+Z` / `Ctrl+Shift+Z` 로 되돌리고 다시 합니다. **저장** <!-- en: Save --> 은 PNG 로 씁니다. JPEG 처럼 PNG 가 아닌 파일을 고쳐 저장하면 원본은 두고 같은 폴더에 같은 이름의 `.png` 를 만들어 그 파일로 넘어갑니다. 그 `.png` 가 이미 있으면 덮어쓰지 않고 저장할 경로를 묻습니다. 이때 입력칸 위에 이미 있다는 안내가 뜨고, 입력칸에는 `이름-1.png` 처럼 아직 없는 이름이 이름 부분이 선택된 채로 들어 있습니다.
- 파일을 읽지 못하면 캔버스에 이유를 보여 줍니다 — **이미지를 찾을 수 없습니다** <!-- en: Image not found --> (경로 표시), **권한이 없습니다** <!-- en: Permission denied -->, **이미지를 열 수 없습니다** <!-- en: Can't open this image --> (손상됐거나 지원하지 않는 형식, 디코더 메시지 표시), **이미지가 너무 커서 열 수 없습니다** <!-- en: Image is too large to open --> (한 변이 16384px를 넘거나 디코딩에 512MiB보다 많은 메모리가 필요한 그림은 열지 않고, 그림의 실제 크기를 보여 줌). 너무 큰 그림을 뺀 나머지 경우에는 **다시 시도** <!-- en: Retry --> 를 누르면 다시 읽습니다. 파일이 돌아오거나 바뀌면 자동으로도 다시 읽습니다.
- 이미지에서 붙여넣기 단축키(기본 `Ctrl+V`)를 누르면 클립보드의 이미지를 떠 있는 선택 영역으로 붙여넣습니다. 클립보드에 이미지가 없으면 아무 일도 하지 않습니다. `tasty image paste --surface <ID>` 도 같습니다.
- `tasty image list` 는 **윈도우가 여러 개여도** 열려 있는 이미지를 전부 보여줍니다.
- `tasty image reload --surface <ID>` 는 기다리지 않고 지금 다시 읽습니다.

```sh
tasty image list
tasty image open --surface 5 shot.png
tasty image export --surface 5 out.png
```

## HTML

로컬 HTML 파일이나 URL 을 OS 의 웹 뷰로 띄웁니다. **새 HTML...** 을 누르면 **HTML 열기** <!-- en: Open HTML --> 창에 URL 또는 파일 경로를 입력합니다.

- 로드 중이면 **불러오는 중…** <!-- en: Loading… -->, 실패하면 **불러오지 못했습니다** <!-- en: Failed to load --> 와 URL 이 보입니다.
- 메뉴나 팝업이 열려 있는 동안에는 HTML · 마크다운 페이지가 잠시 숨고 빈 패널만 보입니다. 알림 카드가 뜨면 카드와 겹치는 페이지만 카드가 사라질 때까지 숨고, 다른 페이지는 그대로 보입니다. 지금 글자를 입력하고 있는 페이지는 숨기지 않으므로 그 위의 알림 카드는 가려집니다.
- **설정** > **외관** 의 **HTML** 항목 — **기본 확대** <!-- en: Default zoom --> · **색 구성표** <!-- en: Color scheme --> (**테마 따름** <!-- en: Follow theme --> / 라이트 / 다크) · **원격 콘텐츠 허용** <!-- en: Allow remote content --> · **스크립트 샌드박스** <!-- en: Sandbox scripts -->. 원격 콘텐츠와 스크립트는 기본적으로 막혀 있습니다. 로컬에서 만든 미리보기를 보는 용도라 외부 사이트를 열 때는 **원격 콘텐츠 허용** 을 켜고 **스크립트 샌드박스** 를 꺼야 합니다.

### 스크립트가 막힌 문서

**스크립트 샌드박스** 가 켜져 있을 때 스크립트가 있는 문서를 보면 페이지 위에 **이 문서의 스크립트가 차단되었습니다** <!-- en: Scripts in this document are blocked --> 안내가 뜹니다. 안내는 페이지를 가리지 않고 페이지를 그만큼 아래로 내립니다. HTML 화면이 좁으면 버튼이 설명 아래 줄로 내려갑니다.

- **이 문서에서 허용** <!-- en: Allow for this document --> — 이 문서만 스크립트를 켜고 한 번 다시 불러옵니다. 다른 문서로 이동하거나 Tasty 를 다시 시작하면 다시 막힙니다. 허용한 문서의 탭에는 스크립트 파일 아이콘이 붙습니다.
- 화면이 새 문서를 불러오는 동안에는 **이 문서에서 허용** 을 누를 수 없습니다. 버튼에 포인터를 올리면 **문서를 다 불러오면 사용할 수 있습니다** <!-- en: Available when the document finishes loading --> 가 뜹니다. 링크·뒤로 가기·다시 불러오기로 직접 연 문서에 스크립트가 있으면 버튼이 다시 켜지고, 없으면 안내가 사라집니다. 에이전트가 연 문서라면 그 탭을 다시 볼 때 안내가 뜹니다.
- 안내 오른쪽 위 **×** — 허용하지 않고 안내만 닫습니다. 탭 제목 뒤에 자물쇠 아이콘이 남고, 자물쇠를 누르면 안내가 다시 뜹니다. 자물쇠를 눌러도 탭은 바뀌지 않습니다.
- 에이전트가 연 문서나 세션 복원으로 다시 열린 문서는 사람이 그 탭을 볼 때 안내가 뜹니다. 에이전트는 스크립트를 허용할 수 없고 상태만 조회합니다.
- 문서를 불러오지 못해 **불러오지 못했습니다** <!-- en: Failed to load --> 가 보이는 동안에는 안내와 탭의 자물쇠·스크립트 아이콘이 사라집니다. 다시 불러온 문서가 열리면 그 문서를 기준으로 다시 정해집니다.

```sh
tasty html open --surface 5 ./dist/index.html
tasty new tab --pane 1 --type html --url http://localhost:3000
tasty surface html-script --surface 5   # 스크립트 감지 결과·허용 여부·안내 상태 조회
```

## Git 보기

사이드바 **도구** > **Git** 을 누르면 현재 터미널 디렉터리의 저장소를 읽기 전용으로 보여주는 창이 뜹니다.

- **변경 사항** <!-- en: Changes --> (status) · **커밋** <!-- en: Commits --> (log) · 파일 클릭 시 **Diff**.
- 왼쪽 **워크트리** <!-- en: Worktrees --> 목록에서 다른 worktree 를 골라 그 기준으로 봅니다. 실제 checkout 은 바뀌지 않습니다.
- **새로고침** <!-- en: Refresh --> 으로 외부 변경을 반영합니다. 커밋 · 스테이징 같은 쓰기는 없습니다.
- **Git 뷰어 열기** <!-- en: Open Git Viewer --> 단축키는 **설정** > **단축키** > **플러그인** <!-- en: Plugins --> 에서 지정합니다(기본값 없음).

현재 디렉터리가 Git 저장소라면 이 창과 별개로 상태바에서 브랜치 이름을 볼 수 있습니다([첫 화면 둘러보기](../getting-started/first-look.md#상태바)).

## 빈 서피스

파일을 닫았거나 아직 종류를 정하지 않은 자리는 **빈 화면** <!-- en: Empty --> 으로 남고 가운데에 종류 선택 버튼이 있습니다. 누르면 [종류 바꾸기](panes-tabs-splits.md#종류-바꾸기) 팝업과 같습니다.

탐색기는 Tasty 에 내장되어 있고, 마크다운 · 이미지 · HTML · Git 보기는 번들 플러그인입니다. 플러그인을 끄면 해당 종류로 열 수 없습니다 — [플러그인](../plugins/index.md).
