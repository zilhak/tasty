# 파일 열기

이 페이지를 읽으면 터미널이 아닌 서피스 — 탐색기 · 마크다운 · 이미지 · HTML — 로 파일을 열고 다루는 방법과, git 상태를 보는 창을 여는 방법을 알게 됩니다.

## 여는 방법

| 어디서 | 어떻게 |
|--------|--------|
| 사이드바 **도구** <!-- en: Tools --> > **파일 열기…** <!-- en: Open File… --> | Tasty 자체 파일 선택 창. 원격 워크스페이스에서는 원격 파일을 보여줍니다 |
| 파일을 창 위로 드래그 | **여기에 드롭하여 열기** <!-- en: Drop to open --> 가 뜨면 놓습니다 |
| 탐색기 서피스 | 파일 더블클릭 |
| 터미널 | `Ctrl+클릭`, 또는 경로를 선택하고 우클릭 > **파일 열기** <!-- en: Open File --> ([터미널 다루기](terminal.md#링크와-경로-열기)) |
| 탭 스트립 빈 곳 우클릭 | **새 마크다운...** <!-- en: New Markdown... --> · **새 탐색기** <!-- en: New Explorer --> · **새 HTML...** <!-- en: New HTML... --> · **새 이미지** <!-- en: New Image --> |
| `Alt+'` | 현재 서피스를 다른 종류로 바꿉니다 ([종류 바꾸기](panes-tabs-splits.md#종류-바꾸기)) |
| CLI | `tasty new tab --pane 1 --type markdown --file README.md` 등 |

파일 확장자에 따라 어떤 서피스로 열지가 정해집니다 — `.md` 는 마크다운, 이미지 파일은 이미지, `.html` 은 HTML, 폴더는 탐색기. 후보가 여럿이거나 없으면 **파일 핸들러 선택** <!-- en: Choose file handler --> 창이 떠서 고르게 하고, 고른 것은 **최근 선택** <!-- en: Recent --> 에 남습니다. 확장자 매핑과 핸들러는 **설정** > **핸들러** <!-- en: Handler --> 탭에서 바꿉니다.

파일로 연 서피스는 다른 서피스와 똑같이 분할 · 이동 · 닫기 · 재시작 복원의 대상입니다. 탭 이름은 파일명이 됩니다.

## 탐색기

Tasty 안에 들어 있는 파일 관리자입니다. 터미널에서 `Alt+'` > **탐색기** 로 바꾸면 그 터미널의 현재 디렉터리를 루트로 엽니다. `tasty new tab --pane 1 --type explorer --path ~/proj` 로도 엽니다.

### 화면

- **왼쪽** — **파일** <!-- en: Files --> 트리(루트 고정)와 그 아래 **즐겨찾기** <!-- en: Favorites -->.
- **위쪽** — **뒤로** <!-- en: Back --> · **앞으로** <!-- en: Forward --> · **위로** <!-- en: Up --> · **새로고침** <!-- en: Refresh -->, 주소창, 보기 전환(**그리드** <!-- en: Grid --> · **목록** <!-- en: List --> · **상세** <!-- en: Detail -->).
- **오른쪽** — 현재 폴더의 항목. 맨 위 `..` 로 상위 폴더에 갑니다. 상세 보기에서는 **이름** · **크기** · **수정일** · **형식** 열 제목을 클릭해 정렬합니다.
- 서피스 안에 **새 탭** <!-- en: New tab --> 을 여러 개 두고 폴더를 따로따로 볼 수 있습니다. 페인의 탭과는 별개입니다.

주소창을 클릭하면 경로를 직접 입력할 수 있고, 최근 방문한 폴더가 자동완성으로 뜹니다. `Enter` 또는 **이동** <!-- en: Go --> 으로 갑니다. 왼쪽 트리는 루트에 고정되지만 오른쪽 목록은 어디로든 갈 수 있습니다.

### 단축키 (탐색기에 포커스가 있을 때)

| 하는 일 | 단축키 |
|---------|--------|
| 새로고침 | `F5` |
| 상위 폴더로 | `Alt+↑` |
| 전체 선택 | `Ctrl+A` · `Alt+A` |
| 경로 복사 | `Alt+Shift+C` |
| 복사 / 잘라내기 / 붙여넣기 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` (터미널과 같은 바인딩) |

클릭으로 선택, `Ctrl+클릭` 으로 추가, `Shift+클릭` 으로 범위 선택.

### 우클릭 메뉴

- **경로 복사** <!-- en: Copy Path --> — 여러 개면 줄바꿈으로 이어 붙입니다.
- **복사** <!-- en: Copy --> · **잘라내기** <!-- en: Cut --> · **붙여넣기** <!-- en: Paste --> · **붙여넣기 (안으로)** <!-- en: Paste (into) --> — 같은 이름이 있으면 `(copy)` 가 붙습니다.
- **휴지통으로 이동** <!-- en: Move to Trash --> — 확인 없이 OS 휴지통으로 보냅니다. 되돌리려면 휴지통에서.
- **이름 변경** <!-- en: Rename -->.
- **시스템에서 열기** <!-- en: Open in System --> — OS 파일 관리자로 폴더를 엽니다.
- **새 탭으로 열기** <!-- en: Open in New Tab --> — 그 폴더를 루트로 하는 탐색기 탭을 페인에 하나 더 엽니다.
- **이 폴더로 루트 설정** <!-- en: Set as Root --> — 왼쪽 트리의 루트를 옮깁니다.
- **즐겨찾기에 추가** <!-- en: Add to Favorites --> — 이름을 붙여 왼쪽 아래 목록에 둡니다. 즐겨찾기는 모든 탐색기가 공유하며 `~/.tasty/explorer-favorites.toml` 에 저장됩니다.

마지막으로 고른 보기 방식은 기억되어 새 탐색기에도 적용됩니다. 탐색기 폰트는 **설정** > **외관** <!-- en: Appearance --> 의 **Explorer** 항목에서 따로 지정합니다. 원격 워크스페이스의 탐색기는 둘러보기만 되고 파일을 바꾸는 항목은 나오지 않습니다.

## 마크다운

`.md` 파일을 렌더해 보여줍니다. 파일이 바뀌면 1 초 안에 자동으로 다시 그립니다.

- 표 · 체크박스 · 각주 · 코드 강조 · `mermaid` 다이어그램 · `$…$` 수식 · `> [!NOTE]` 콜아웃(Obsidian 식 `[!tip]-` 접기 포함) · 맨 위 frontmatter 숨김.
- 제목이 있으면 본문 위에 접을 수 있는 **목차** <!-- en: Table of contents --> 가 붙습니다.
- 코드 블록에 마우스를 올리면 **코드 복사** <!-- en: Copy code --> 버튼.
- 문서에 포커스가 있을 때 `Ctrl+F` (macOS `Cmd+F`) — **문서 내 검색** <!-- en: Find in document -->.
- 맨 위 주소창에 다른 파일 경로를 입력해 이동합니다. 최근 연 파일이 자동완성으로 뜹니다.
- 문서 안의 링크 — 다른 마크다운 · 파일은 같은 페인의 새 탭으로 열리고, `http(s)://` 는 브라우저로 갑니다. 상대 경로는 그 문서가 있는 폴더 기준입니다.
- 1MB 를 넘는 파일은 **큰 파일을 열까요?** <!-- en: Open large file? --> 로 한 번 묻습니다.

**새 마크다운...** 이나 `Alt+'` > **마크다운** 은 **마크다운 파일 열기** <!-- en: Open Markdown File --> 창을 띄웁니다. 경로를 입력하거나 **찾아보기…** <!-- en: Browse… --> 로 고릅니다.

```sh
tasty markdown recent
tasty markdown reload --surface 5
```

## 이미지

PNG · JPEG 등을 보고, 간단히 그립니다. **새 이미지** 는 빈 캔버스로 시작합니다.

- 툴바 — **이전 이미지** <!-- en: Previous image --> / **다음 이미지** <!-- en: Next image --> (같은 폴더 안), **새로고침** <!-- en: Refresh -->, **편집** <!-- en: Edit -->, **새 이미지** <!-- en: New image -->, 확대 **Fit** / `+` / `-`.
- **편집** 을 누르면 **굵기** <!-- en: Brush --> · **색상** <!-- en: Color --> 을 고르고 위에 그립니다. `Ctrl+Z` / `Ctrl+Shift+Z` 로 되돌리고 다시 합니다. **저장** <!-- en: Save --> 은 PNG 로 씁니다.
- `tasty image paste --surface <ID>` 로 클립보드의 이미지를 떠 있는 선택 영역으로 붙여넣습니다.
- `tasty image list` 는 **창이 여러 개여도** 열려 있는 이미지를 전부 보여줍니다.

```sh
tasty image list
tasty image open --surface 5 shot.png
tasty image export --surface 5 out.png
```

## HTML

로컬 HTML 파일이나 URL 을 OS 의 웹 뷰로 띄웁니다. **새 HTML...** 을 누르면 **HTML 열기** <!-- en: Open HTML --> 창에 URL 또는 파일 경로를 입력합니다.

- 로드 중이면 **불러오는 중…** <!-- en: Loading… -->, 실패하면 **불러오지 못했습니다** <!-- en: Failed to load --> 와 URL 이 보입니다.
- **설정** > **외관** 의 **HTML** 항목 — **기본 확대** <!-- en: Default zoom --> · **색 구성표** <!-- en: Color scheme --> (**테마 따름** <!-- en: Follow theme --> / 라이트 / 다크) · **원격 콘텐츠 허용** <!-- en: Allow remote content --> · **스크립트 샌드박스** <!-- en: Sandbox scripts -->. 원격 콘텐츠와 스크립트는 기본적으로 막혀 있습니다. 로컬에서 만든 미리보기를 보는 용도라 외부 사이트를 열 때는 이 두 항목을 켜야 합니다.

```sh
tasty html open --surface 5 ./dist/index.html
tasty new tab --pane 1 --type html --url http://localhost:3000
```

## Git 보기

사이드바 **도구** > **Git** 을 누르면 현재 터미널 디렉터리의 저장소를 읽기 전용으로 보여주는 창이 뜹니다.

- **변경 사항** <!-- en: Changes --> (status) · **커밋** <!-- en: Commits --> (log) · 파일 클릭 시 **Diff**.
- 왼쪽 **워크트리** <!-- en: Worktrees --> 목록에서 다른 worktree 를 골라 그 기준으로 봅니다. 실제 checkout 은 바뀌지 않습니다.
- **새로고침** <!-- en: Refresh --> 으로 외부 변경을 반영합니다. 커밋 · 스테이징 같은 쓰기는 없습니다.
- **Git 뷰어 열기** <!-- en: Open Git Viewer --> 단축키는 **설정** > **단축키** > **플러그인** <!-- en: Plugins --> 에서 지정합니다(기본값 없음).

상태바의 브랜치 이름은 이 창과 별개로 항상 표시됩니다([첫 화면 둘러보기](../getting-started/first-look.md#상태바)).

## 빈 서피스

파일을 닫았거나 아직 종류를 정하지 않은 자리는 **빈 화면** <!-- en: Empty --> 으로 남고 가운데에 종류 선택 버튼이 있습니다. 누르면 [종류 바꾸기](panes-tabs-splits.md#종류-바꾸기) 팝업과 같습니다.

탐색기는 Tasty 에 내장되어 있고, 마크다운 · 이미지 · HTML · Git 보기는 번들 플러그인입니다. 플러그인을 끄면 해당 종류로 열 수 없습니다 — [플러그인](../plugins/index.md).
