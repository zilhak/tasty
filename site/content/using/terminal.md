# 터미널 다루기

이 페이지를 읽으면 터미널 서피스에서 복사 · 붙여넣기 · 검색 · 링크 열기 · 스크롤을 하고, 마우스를 잡는 프로그램과 알림이 어떻게 보이는지 알게 됩니다. 단축키는 기본 프리셋(**Tasty**) 값이며 `Alt` 는 macOS 에서 `Cmd` 입니다.

## 셸

**설정** > **터미널** <!-- en: Terminal --> 에서 정합니다.

- **셸** <!-- en: Shell --> — 실행할 셸. Windows 는 Git for Windows 의 bash 를 찾고, 없으면 경로를 직접 지정하라고 알립니다.
- **시작 명령어** <!-- en: Startup command --> — 새 터미널마다 처음에 입력할 한 줄.
- **작업 디렉토리 상속** <!-- en: Inherit working directory --> — 새 터미널을 현재 터미널의 디렉터리에서 시작합니다(기본 켜짐).
- **실행 중 프로세스 닫기 확인** <!-- en: Confirm close running process --> — 프로그램이 돌고 있는 터미널을 닫을 때 확인합니다.

bash(4.4 이상)와 zsh 는 별도 설정 없이 셸 통합이 붙습니다. 탭 이름이 현재 디렉터리를 따라가고, 상태바에 git 브랜치가 뜨고, 명령이 끝났을 때 훅을 걸 수 있습니다([훅 · 알림](../agents/hooks-notifications.md)). fish 등 다른 셸은 직접 설정해야 하며, 그럴 때 **셸 통합이 감지되지 않았습니다** <!-- en: Shell integration not detected --> 배너가 뜰 수 있습니다.

프로그램이 종료해 셸이 끝나면 그 서피스는 자동으로 닫힙니다.

## 복사 · 붙여넣기

| 하는 일 | 단축키 |
|---------|--------|
| 복사 | `Ctrl+C` · `Alt+C` · `Ctrl+Shift+C` |
| 붙여넣기 | `Ctrl+V` · `Alt+V` · `Ctrl+Shift+V` |
| 복사 모드 진입 | `Ctrl+Shift+Space` |

- `Ctrl+C` 는 선택 영역이 있으면 복사, 없으면 평소처럼 프로그램을 중단합니다.
- 붙여넣기 직후 0.5 초 안의 `Ctrl+C` 는 무시됩니다 — `Ctrl+V` 옆 키를 잘못 눌러 입력을 날리는 사고를 막습니다. 무시되면 토스트로 알립니다.
- 클립보드에 텍스트가 없고 이미지가 있으면 PNG 파일로 저장한 뒤 그 경로를 붙여넣습니다. 에이전트에게 스크린샷을 건넬 때 씁니다.
- 윈도우 폭 때문에 접힌 줄은 복사할 때 한 줄로 합쳐집니다.

### 선택

드래그(문자) · 더블클릭(단어) · 트리플클릭(줄). 선택은 스크롤백까지 이어집니다. 선택 후 우클릭하면 **복사** <!-- en: Copy --> · **줄바꿈 없이 복사** <!-- en: Copy Without Line Breaks --> · **터미널 ID 복사** <!-- en: Copy Terminal ID --> 메뉴가 뜹니다. 선택한 글자가 실제 파일 · 폴더 경로면 **파일 열기** <!-- en: Open File --> / **폴더 열기** <!-- en: Open Folder --> 도 나타납니다.

### 복사 모드 (vi)

마우스 없이 화면과 스크롤백을 돌아다니며 복사합니다. `Ctrl+Shift+Space` 로 들어갑니다. vim 처럼 전체 화면을 쓰는 프로그램이 떠 있는 동안은 들어갈 수 없습니다.

| 키 | 동작 |
|----|------|
| `h` `j` `k` `l` | 이동. 앞에 숫자를 붙이면 반복 |
| `w` `b` `e` / `W` `B` `E` | 단어 단위 이동 |
| `0` `^` `$` | 줄 처음 / 첫 글자 / 줄 끝 |
| `gg` `G` / `H` `M` `L` | 맨 위 / 맨 아래 / 화면 위 · 가운데 · 아래 |
| `v` / `V` | 문자 / 줄 선택 시작 |
| `y` | 복사하고 나갑니다 |
| `/` `?` `n` `N` | 아래 · 위로 검색, 다음 · 이전 결과 |
| `"+` `"*` | 다음 복사의 대상 클립보드 지정 |
| `q<문자>` … `q` / `@<문자>` | 매크로 녹화 / 재생 |
| `Esc` | 선택 해제. 선택이 없으면 나갑니다 |

### 프로그램의 클립보드 접근 (OSC 52)

터미널 안 프로그램(tmux, 원격 vim 등)이 클립보드에 **쓰는** 것은 항상 됩니다. **읽는** 것은 **설정** > **터미널** > **클립보드 읽기 허용 (OSC 52)** <!-- en: Allow clipboard read (OSC 52) --> 을 켜야 합니다. 기본은 꺼짐이며, 켜면 SSH 너머의 프로그램도 클립보드 내용을 가져갈 수 있으니 주의합니다.

### 스크립트에서 클립보드에 쓰기

스크립트나 에이전트가 클립보드에 텍스트를 직접 넣을 수 있습니다.

```sh
tasty clipboard set-text "복사해 둘 내용"
```

## 검색

`Ctrl+F` 또는 `Alt+F`, 또는 탭 스트립의 검색 아이콘. 서피스 위쪽 가운데에 검색 바가 뜹니다.

- `Enter` / `Shift+Enter` / `↑` `↓` — 다음 / 이전 결과. 결과 수가 `3/42` 로 보이고 화면이 따라갑니다.
- 오른쪽 토글 — **대소문자 구분** <!-- en: Match case --> · **정규식** <!-- en: Regular expression --> · **단어 단위 일치** <!-- en: Match whole word -->.
- 검색 바에 커서가 있을 때 `Esc` 또는 `×` — 닫기. 검색 바가 떠 있어도 터미널에 커서가 있으면 키 입력은 그대로 터미널로 갑니다. `Ctrl+F` 를 다시 누르면 검색 바와 터미널 사이를 오갑니다.

## 링크와 경로 열기

`Ctrl` 을 누른 채 URL 이나 경로에 마우스를 올리면 파란 밑줄이 생기고, 클릭하면 브라우저 또는 연결된 프로그램으로 엽니다. 경로는 `src/main.rs` 같은 상대 경로도 되지만 현재 디렉터리 기준으로 실제 있는 것만 링크가 됩니다.

수식키는 **설정** > **터미널** > **링크 클릭 수식키** <!-- en: Link click modifier --> 에서 `Ctrl` · `Alt` · **없음 (일반 클릭)** <!-- en: None (plain click) --> 중 고릅니다. 없음으로 두면 일반 클릭이 링크를 열어 텍스트 선택과 겹칩니다.

파일이 열리는 방식(마크다운 · 이미지 · 탐색기)은 [파일 열기](files.md). 파일을 터미널 위로 드래그해 놓으면(**여기에 드롭하여 열기** <!-- en: Drop to open -->) 같은 규칙으로 열립니다.

## 스크롤

- 마우스 휠, 또는 `PageUp` / `PageDown` (한 화면씩) 으로 스크롤백을 봅니다. 타이핑하면 맨 아래로 돌아옵니다.
- vim · less · htop 처럼 화면 전체를 쓰는 프로그램 안에서는 휠과 `PageUp` / `PageDown` 이 프로그램으로 전달됩니다.
- 보관 줄 수는 **설정** > **터미널** > **스크롤백 줄 수** <!-- en: Scrollback lines --> (기본 10,000, 최대 100,000). `clear` 는 스크롤백도 비웁니다.
- 재시작 후에도 스크롤백이 이어집니다 — [워크스페이스](workspaces.md#재시작-후-복원).

글자 크기는 `Ctrl+=` / `Ctrl+-` 로 키우고 줄이며 `Ctrl+0` 으로 되돌립니다. 터미널 폰트에만 적용됩니다.

## 마우스를 잡는 프로그램

vim(`:set mouse=a`) · htop · Claude Code 처럼 마우스를 직접 쓰는 프로그램이 뜨면 클릭과 드래그가 그 프로그램으로 넘어갑니다. 처음 클릭할 때 배너가 뜹니다.

> **마우스 입력 캡처 중** <!-- en: Mouse input captured --> — 이 앱이 마우스를 캡처하고 있습니다. 텍스트 선택은 Shift+드래그, tasty 메뉴는 Shift+우클릭을 사용하세요.

- `Shift+드래그` — 텍스트 선택. `Shift+더블클릭` 은 단어.
- `Shift+우클릭` — Tasty 의 복사 메뉴.
- 배너는 프로그램이 끝나면 저절로 닫힙니다. `×` 로 바로 닫아도 됩니다.
- 배너에 마우스를 올리면 나오는 **더 보기** <!-- en: More options --> 에서 그 프로그램에 대해 **이 알림 끄기** 또는 **마우스 캡처 비활성화** 를 고릅니다. 비활성화하면 그 프로그램 위에서는 클릭이 평소처럼 선택으로 동작하고 휠만 프로그램으로 갑니다.

같은 항목은 **설정** > **터미널** > **마우스 캡처** <!-- en: Mouse Capture --> 에 있습니다 — **마우스 캡처 안내 표시** <!-- en: Show mouse-capture hint --> 토글, **다음 프로그램에서 마우스 캡처 비활성화** <!-- en: Disable mouse capture for these programs --> 목록, **다음 프로그램에서 캡처 안내 배너만 억제** <!-- en: Suppress the capture hint banner for these programs --> 목록. 이름은 부분 일치이고 `ht*` 같은 와일드카드를 씁니다.

## 실행 중 · 확인 필요 표시

- 탭의 **녹색 점**, 사이드바 카드의 점 — 셸이 아닌 프로그램이 출력을 내는 중. 입력을 기다리며 멈춰 있으면 사라집니다.
- 서피스의 **노란 테두리** — 프로그램이 응답을 기다립니다(에이전트가 질문한 경우). **파란 테두리** — 명령이 끝났거나 알림이 왔습니다. 그 서피스를 클릭하면 사라집니다. 탭 이름과 사이드바 배지도 같은 색을 씁니다.

## 알림

터미널 벨(`\a`)과 프로그램이 보내는 알림 시퀀스(OSC 9 · 99 · 777)를 모아 보여줍니다.

- `Ctrl+Shift+I` — **알림** <!-- en: Notifications --> 패널. 최신순 목록과 **이동** <!-- en: Jump --> 버튼, **모두 읽음** <!-- en: Mark all read -->. 열면 전부 읽음 처리됩니다. 타이틀바의 전체화면 버튼으로 크게 볼 수 있습니다([전체화면](panes-tabs-splits.md#전체화면)).
- 윈도우가 뒤에 있으면 OS 알림으로도 띄웁니다.
- **설정** > **알림** <!-- en: Notifications --> — **알림 활성화** <!-- en: Notifications enabled --> · **소리** <!-- en: Sound --> · **알림 병합 간격 (ms)** <!-- en: Coalesce interval (ms) --> (같은 곳에서 연달아 온 알림을 하나로 합치는 간격, 기본 500).
- 벨만 끄려면 **설정** > **터미널** > **벨 알림 표시** <!-- en: Show bell notification -->.

스크립트에서 직접 알림을 띄우려면 `tasty notify "빌드 끝" --title build`.

## 플랫폼별 참고

- **macOS** — **설정** > **터미널** > **Option 을 Meta 로 사용** <!-- en: Use Option as Meta --> 을 켜면 `Option+F` 같은 조합이 특수문자 대신 readline · Emacs 의 Meta 키로 들어갑니다(기본 꺼짐).
- **Windows** — 절전에서 깨어난 뒤 터미널이 응답하지 않을 수 있습니다. Tasty 가 깨우기를 시도하고, 그래도 멈춘 것으로 보이면 알림으로 알립니다. 그때는 그 터미널을 새로 엽니다.
- 화면 전체가 번쩍이는 프로그램(readline 의 visible bell 등)이 거슬리면 **설정** > **터미널** > **화면 반전 플래시 (DECSCNM)** <!-- en: Reverse-screen flash (DECSCNM) --> 을 끕니다.

## 그 밖에

- 색과 폰트는 [테마](../customize/themes.md)와 **설정** > **외관** <!-- en: Appearance -->. 폰트는 D2Coding 이 내장되어 있어 따로 설치하지 않아도 됩니다.
- Sixel · Kitty 이미지 프로토콜은 지원하지 않습니다. 이미지는 [이미지 서피스](files.md#이미지)로 봅니다.
- 스크립트나 에이전트가 이 터미널에 명령을 보내고 출력을 읽는 방법은 [tasty CLI](../agents/cli.md). 상태바의 숫자가 그 터미널의 ID 입니다.
