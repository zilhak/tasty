# 워크스페이스

이 페이지를 읽으면 워크스페이스를 만들고, 이름을 붙이고, 카테고리로 묶고, 전환하고, 닫았다가 되살리는 방법을 알게 됩니다. 워크스페이스가 무엇인지는 [첫 화면 둘러보기](../getting-started/first-look.md)에 있습니다.

## 만들기

| 방법 | 동작 |
|------|------|
| 사이드바 맨 아래 **새 워크스페이스** <!-- en: New Workspace --> 버튼 | 터미널 하나짜리 워크스페이스를 만듭니다 |
| `Alt+N` (macOS `Cmd+N`) | 같은 동작 |
| **새 워크스페이스** 버튼 우클릭 > **프리셋으로 새 워크스페이스 생성...** <!-- en: Create workspace from preset... --> | 저장해 둔 레이아웃 프리셋으로 만듭니다 ([레이아웃 저장](panes-tabs-splits.md#레이아웃-저장--프리셋)) |
| 사이드바 빈 곳 우클릭 > **원격 워크스페이스 추가** <!-- en: Add remote workspace --> | 다른 머신의 tasty 를 미러링합니다 ([원격 attach](../remote/attach.md)) |

새 워크스페이스의 터미널은 현재 터미널의 작업 디렉터리에서 시작합니다(**설정** > **터미널** <!-- en: Terminal --> > **작업 디렉토리 상속** <!-- en: Inherit working directory -->, 기본 켜짐).

터미널이 아닌 서피스로 시작하거나 이름을 정해서 만들려면 CLI 를 씁니다.

```sh
tasty new workspace --name build --cwd ~/proj
tasty new workspace --type explorer --path ~/proj
tasty new workspace --type markdown --file README.md
```

## 이름 · 부제목

기본 이름은 `Workspace 1` 같은 순번입니다. 사이드바 카드를 우클릭하면 바꿀 수 있습니다.

- **이름 변경** <!-- en: Rename --> — 단축키 `F3`.
- **부제목 변경** <!-- en: Change Subtitle --> — 카드 아래 작은 글씨. 단축키 `F4`.

```sh
tasty set workspace --id 3 --name api --subtitle "port 8080"
tasty list workspaces
```

## 전환

- 사이드바 카드 클릭.
- `Alt+1` ~ `Alt+9` (macOS `Cmd+1` ~). `Alt` 를 누르고 있으면 카드 옆에 숫자 키캡이 떠서 어느 번호인지 보여줍니다.
- `Alt+J` / `Alt+K` — 다음 / 이전 워크스페이스. 끝에서는 반대쪽으로 돕니다.
- 알림 패널의 **이동** <!-- en: Jump --> 버튼 — 알림을 보낸 워크스페이스로.

수식키와 숫자 키는 **설정** > **단축키** <!-- en: Keybindings --> 의 **워크스페이스 전환 수식키** <!-- en: Workspace switch modifier --> 항목에서 바꿉니다.

워크스페이스마다 포커스된 페인을 따로 기억합니다. 오갔다 돌아와도 커서가 있던 자리가 유지됩니다. 전환하면 사이드바 목록이 자동으로 스크롤해 활성 카드를 보이게 합니다.

## 순서 바꾸기

- 카드를 드래그합니다.
- 카드 우클릭 > **위로 이동** <!-- en: Move Up --> / **아래로 이동** <!-- en: Move Down -->.
- `tasty move workspace --id 5 --to 0` — 옮길 워크스페이스를 **ID 로** 지정합니다. 윈도우가 여러 개여도 그 ID 를 가진 윈도우에서 옮겨집니다. ID 는 `tasty list workspaces` 에 나옵니다.
- `tasty move workspace --from 2 --to 0` (0 부터 셉니다) — 순번은 **윈도우 안의 자리**라, 윈도우가 여러 개면 지금 보고 있는 윈도우에서 옮겨집니다.

## 카드에 붙는 표시

| 표시 | 뜻 |
|------|----|
| 이름 왼쪽 점 | 그 워크스페이스 안에서 프로그램이 실행 중 (`● 3` 처럼 개수 병기) |
| 이름 오른쪽 숫자 배지 | 확인이 필요한 서피스 개수. 노란색은 입력을 기다리는 것, 파란색은 작업이 끝난 것. 그 서피스를 클릭하면 사라집니다 |
| **REMOTE** 알약 | 원격 tasty 를 미러링한 워크스페이스 |
| 빨간 표시 | 다른 사용자가 원격으로 점유 중 |

사이드바를 접으면(**접기** <!-- en: Collapse -->, `Ctrl+B`) 카드가 정사각 아이콘이 되고 표시는 점 하나로 합쳐집니다.

## 닫기와 복원

- 카드 우클릭 > **워크스페이스 닫기** <!-- en: Close Workspace -->, 또는 `Alt+Shift+W`.
- `Ctrl+W` 는 **활성 항목 닫기** <!-- en: Close active --> 입니다 — 탭이 하나 남았으면 페인을, 페인도 하나면 워크스페이스를 닫습니다.

원격에서 attach 해 쓰고 있는 터미널이 들어 있으면 닫히지 않고 안내가 뜹니다. 그 터미널
에서 지금 다른 사람이 작업 중이고, 닫으면 그 세션이 예고 없이 끝나기 때문입니다. 회수
하려면 점유 표시 위의 **강제 끊기** <!-- en: Force detach --> 를 누른 뒤 다시 닫습니다.

닫은 워크스페이스 · 페인 · 탭 · 서피스는 `Ctrl+Shift+T` (**닫은 항목 복원** <!-- en: Restore closed -->) 로 마지막에 닫은 것부터 되살립니다. 터미널의 스크롤백도 함께 돌아옵니다. 단 셸은 새로 시작하므로 실행 중이던 프로그램은 돌아오지 않습니다. 이 목록은 메모리에만 있어 Tasty 를 종료하면 사라집니다.

## 카테고리(폴더)로 묶기

워크스페이스가 많아지면 **설정** > **일반** <!-- en: General --> > **워크스페이스 카테고리(폴더)** <!-- en: Workspace categories (folders) --> 를 켭니다. 사이드바가 접을 수 있는 섹션으로 바뀝니다.

- 기본 섹션 **워크스페이스** <!-- en: Workspaces --> 는 항상 맨 위에 있고 이름을 바꾸거나 지울 수 없습니다.
- 섹션 헤더 클릭 — 접기 / 펼치기. **카테고리 전체 접기/펴기** <!-- en: Collapse/expand all categories --> 단축키는 기본값이 비어 있어 직접 지정합니다.
- 헤더 우클릭 — **워크스페이스 추가** <!-- en: Add workspace --> · **프리셋으로 새 워크스페이스 생성...** · **원격 워크스페이스 추가** · **카테고리 이름 변경** <!-- en: Rename category --> · **카테고리 삭제** <!-- en: Delete category --> · **새 카테고리** <!-- en: New category -->.
- 빈 곳 우클릭 — **새 카테고리** · **원격 워크스페이스 추가**.
- 워크스페이스 카드 우클릭 — **카테고리로 이동** <!-- en: Move to category -->. 다른 섹션으로 드래그해도 됩니다.
- 카테고리를 삭제하면 안의 워크스페이스는 지워지지 않고 **워크스페이스** 섹션으로 돌아갑니다.

카테고리를 켜면 사이드바 아래의 **새 워크스페이스** 버튼은 사라지고 헤더 메뉴로 만듭니다. `Alt+N` 은 현재 워크스페이스가 속한 카테고리에 만듭니다.

전환 단축키도 카테고리 단위가 생깁니다.

| 단축키 | 동작 |
|--------|------|
| `Ctrl+Shift+1` ~ `Ctrl+Shift+0` | n 번째 카테고리로. 접혀 있으면 펼치고, 그 카테고리에서 마지막으로 쓰던 워크스페이스로 갑니다. `Ctrl+Shift` 를 누르고 있으면 헤더에 번호가 뜹니다 |
| `Ctrl+Shift+J` / `Ctrl+Shift+K` | 다음 / 이전 카테고리 |
| `Alt+1` ~ `Alt+9` | 현재 카테고리 **안에서** n 번째 워크스페이스 |
| `Alt+J` / `Alt+K` | 현재 카테고리 안에서 다음 / 이전. 경계를 넘어 다음 카테고리로 가려면 **설정** > **일반** > **다음/이전 워크스페이스가 카테고리 경계를 넘음** <!-- en: Next/prev workspace crosses categories --> 을 켭니다 |

카테고리를 다시 끄면 모든 워크스페이스가 **워크스페이스** 섹션 하나로 합쳐집니다.

```sh
tasty workspace-category list
tasty workspace-category create --name work
tasty new workspace --name api --category work
tasty set workspace --id 3 --category work
```

## 재시작 후 복원

Tasty 를 다시 실행하면 직전 윈도우의 워크스페이스 · 페인 · 탭 · 서피스 배치가 그대로 돌아옵니다. 관련 설정은 **설정** > **일반** 에 있습니다.

- **시작 시 레이아웃 복원** <!-- en: Restore layout on startup --> (기본 켜짐) — 끄면 윈도우를 닫을 때 저장본을 지웁니다.
- **재시작 시 Surface 내용 복원** <!-- en: Restore surface content on restart --> (기본 켜짐) — 각 터미널의 스크롤백까지 보존합니다. 위로 스크롤하면 이전 세션의 출력이 있습니다. 끄면 보관하던 스크롤백 파일을 전부 지웁니다.

복원되지 않는 것 — 실행 중이던 프로그램, 환경 변수, 열려 있던 팝업. 셸은 같은 디렉터리에서 새로 시작합니다. Claude Code 처럼 세션 재개 명령을 남기는 프로그램은 자동으로 다시 실행됩니다([Claude · Codex 와 함께 쓰기](../agents/claude-codex.md)).

저장 파일은 `~/.tasty/layouts/01.json` 입니다. 윈도우를 여러 개 열면 윈도우마다 `02.json`, `03.json` 으로 나뉘고, 다음에 새 윈도우를 열 때 비어 있는 슬롯을 순서대로 이어받습니다. 재시작 시 뜨는 윈도우는 하나이며, 나머지 슬롯은 새 윈도우(`Alt+Shift+N`)을 열 때 복원됩니다.

복원 대상이 아닌 배치를 반복해서 쓰고 싶으면 프리셋으로 저장합니다 — [레이아웃 저장](panes-tabs-splits.md#레이아웃-저장--프리셋).
