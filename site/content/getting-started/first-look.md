# 첫 화면 둘러보기

이 페이지를 읽으면 Tasty 창의 각 부분이 무엇이고 어떤 이름으로 불리는지 알게 됩니다. 이후 페이지는 전부 이 용어로 설명합니다.

## 창의 구성

```
┌──────────────────────────────────────────────┐
│ 타이틀바                                      │
├──────────┬───────────────────────────────────┤
│          │ 탭 스트립                           │
│ 사이드바  ├───────────────────────────────────┤
│          │ 작업 영역 (페인 · 탭 · 서피스)        │
│          ├───────────────────────────────────┤
│          │ 상태바                              │
└──────────┴───────────────────────────────────┘
```

- **타이틀바** — 창을 끌어 옮기고, 더블클릭으로 최대화합니다. Linux · Windows 는 Tasty 가 최소화 · 최대화 · 닫기 버튼을 직접 그리고, macOS 는 왼쪽 신호등 버튼을 그대로 씁니다.
- **사이드바** — 워크스페이스 목록과 도구 · 플러그인 · 설정 진입점.
- **작업 영역** — 실제로 일하는 곳. 아래 네 가지 용어로 이루어집니다.
- **상태바** — 현재 터미널의 상태와 빠른 버튼.

## 네 가지 용어 — 워크스페이스 · 페인 · 탭 · 서피스

Tasty 의 화면은 이 순서로 포함 관계를 이룹니다. 처음 쓸 때 헷갈리면 사이드바의 **도구** <!-- en: Tools --> > **튜토리얼…** <!-- en: Tutorial… --> 을 열어 화면 위에 직접 표시되는 안내를 따라가면 됩니다.

| 용어 | 뜻 | 비슷한 개념 |
|------|----|------------|
| **워크스페이스** <!-- en: Workspace --> | 탭 · 페인 · 서피스를 전부 담는 가장 큰 단위. 사이드바에서 전환합니다 | tmux 의 session, iTerm2 의 window |
| **페인** <!-- en: Pane --> | 워크스페이스를 물리적으로 나눈 칸. 칸마다 **자기 탭 스트립**을 가집니다 | tmux · iTerm2 에는 없는 Tasty 고유 개념 |
| **탭** <!-- en: Tab --> | 페인 안의 탭 하나 | tmux 의 window, iTerm2 의 tab |
| **서피스** <!-- en: Surface --> | 실제로 터미널 · 마크다운 · 탐색기가 그려지는 면. 탭 하나 안에서 여러 개로 분할할 수 있습니다 | tmux · iTerm2 의 pane |

**분할이 두 단계**라는 점이 Tasty 의 특징입니다.

- **페인 분할** — 워크스페이스를 좌우 · 상하로 나눕니다. 어느 페인에서 탭을 바꿔도 다른 페인은 그대로입니다. 예: 왼쪽 페인은 Claude Code 전용, 오른쪽 페인은 로그 · 빌드 탭 여러 개.
- **서피스 분할** — 탭 하나 안을 나눕니다. 탭을 바꾸면 그 분할 전체가 함께 바뀝니다.

자세한 조작은 [페인 · 탭 · 분할](../using/panes-tabs-splits.md).

## 사이드바

위에서부터 세 영역입니다.

- **헤더** — `tasty.` 워드마크와 **접기** <!-- en: Collapse --> 버튼. 접으면 아이콘만 남는 좁은 레일이 됩니다.
- **워크스페이스** <!-- en: WORKSPACES --> 목록 — 카드를 클릭하면 전환, 드래그하면 순서 변경. 맨 아래 **새 워크스페이스** <!-- en: New workspace --> 버튼으로 추가합니다(우클릭하면 프리셋에서 만듭니다). 카드 우측의 숫자 배지는 그 워크스페이스 안에 확인이 필요한 서피스가 몇 개인지입니다.
- **하단 버튼** — **도구** <!-- en: Tools --> (명령 팔레트, 리스닝 포트, 원격 연결, 프리셋, 튜토리얼, 파일 열기, 플러그인이 추가한 항목), **플러그인** <!-- en: Plugins --> (설치 · 활성화 관리 창), **설정** <!-- en: Settings --> (설정 창).

워크스페이스가 많아지면 **설정** > **일반** <!-- en: General --> > **워크스페이스 카테고리(폴더)** <!-- en: Workspace categories (folders) --> 를 켜서 폴더처럼 묶을 수 있습니다. 자세한 내용은 [워크스페이스](../using/workspaces.md).

## 탭 스트립

각 페인의 맨 위에 있습니다.

- 탭마다 종류 아이콘(터미널 · 마크다운 등)과 이름이 보입니다. 이름은 셸의 현재 디렉터리를 따라가고, 우클릭 > **탭 이름 변경** <!-- en: Rename Tab --> 으로 고정할 수 있습니다.
- 실행 중인 프로그램이 있으면 **녹색 점**, 알림이 왔으면 **노란 표시**가 붙습니다.
- `+` 는 새 탭. 우클릭하면 프리셋으로 만듭니다. 그 옆의 분할 · 검색 아이콘은 이 페인을 나누거나 현재 서피스 안을 검색합니다.
- 탭이 넘치면 좌우 화살표가 나타납니다. 드래그로 순서를 바꿉니다.
- 빈 곳을 우클릭하면 **새 터미널** <!-- en: New Terminal --> · **새 마크다운...** <!-- en: New Markdown... --> · **새 탐색기** <!-- en: New Explorer --> · **새 HTML...** <!-- en: New HTML... --> · **새 이미지** <!-- en: New Image --> 로 터미널이 아닌 서피스를 만들 수 있습니다. 종류별 설명은 [파일 열기](../using/files.md).

마지막 남은 탭 하나는 닫히지 않습니다.

## 상태바

작업 영역 맨 아래 한 줄입니다. 왼쪽은 현재 포커스된 서피스의 정보, 오른쪽은 버튼입니다.

- **git 브랜치** — 셸의 현재 디렉터리가 git 저장소면 브랜치 이름. 최대 1초 늦게 반영됩니다.
- **서피스 ID** — 숫자. `tasty` CLI 로 이 터미널을 지정할 때 쓰는 값입니다([tasty CLI](../agents/cli.md)).
- **셸 · 격자 크기** — 앞에서 돌고 있는 프로그램 이름과 `열×행`.
- **팔레트** <!-- en: palette --> 칩 — 클릭하면 명령 팔레트가 열립니다. 칩에 적힌 단축키는 설정을 따라갑니다.
- **테마 점** — 클릭할 때마다 밝은 테마(latte)와 어두운 테마(mocha)를 오갑니다.

## 처음 알아둘 단축키

기본 프리셋(**Tasty**)의 값입니다. 표기의 `Alt` 는 macOS 에서 `Cmd(⌘)`, `Ctrl` 은 `Control(⌃)` 입니다. 바꾸는 방법과 전체 표는 [단축키](../customize/keybindings.md).

| 하는 일 | Windows · Linux | macOS |
|---------|-----------------|-------|
| 새 워크스페이스 | `Alt+N` | `Cmd+N` |
| 새 탭 | `Alt+T` | `Cmd+T` |
| 현재 탭 · 서피스 닫기 | `Ctrl+W` | `Ctrl+W` |
| 닫은 항목 복원 | `Ctrl+Shift+T` | `Ctrl+Shift+T` |
| 페인 분할 (좌우 / 상하) | `Alt+E` / `Alt+Shift+E` | `Cmd+E` / `Cmd+Shift+E` |
| 서피스 분할 (좌우 / 상하) | `Alt+D` / `Alt+Shift+D` | `Cmd+D` / `Cmd+Shift+D` |
| 다음 · 이전 페인 | `Ctrl+]` / `Ctrl+[` | `Ctrl+]` / `Ctrl+[` |
| 다음 · 이전 서피스 | `Alt+]` / `Alt+[` | `Cmd+]` / `Cmd+[` |
| 탭 n 번으로 | `Ctrl+1` ~ `Ctrl+0` | `Ctrl+1` ~ `Ctrl+0` |
| 워크스페이스 n 번으로 | `Alt+1` ~ `Alt+9` | `Cmd+1` ~ `Cmd+9` |
| 사이드바 접기 / 숨기기 | `Ctrl+B` / `Ctrl+Shift+B` | `Ctrl+B` / `Ctrl+Shift+B` |
| 알림 패널 | `Ctrl+Shift+I` | `Ctrl+Shift+I` |
| 명령 팔레트 | `Ctrl+Shift+P` | `Ctrl+Shift+P` |
| 설정 | `Ctrl+,` | `Ctrl+,` |
| 새 창 | `Alt+Shift+N` | `Cmd+Shift+N` |

macOS 에서 iTerm2 식 `⌘` 중심 조합을 원하면 **설정** > **단축키** <!-- en: Keybindings --> 에서 **Mac** 프리셋을 고릅니다.

## 창을 닫으면

창의 닫기 버튼을 누르면 **종료**할지 **백그라운드로 최소화**할지 묻습니다. 백그라운드를 고르면 Tasty 는 시스템 트레이(메뉴 막대)로 들어가고, 트레이 아이콘 메뉴의 **윈도우 표시** <!-- en: Show Window --> 로 돌아옵니다. 매번 묻지 않게 하려면 **설정** > **일반** > **종료 동작** <!-- en: Close behavior --> 을 바꿉니다.

Tasty 를 다시 실행하면 직전 창의 워크스페이스 · 페인 · 탭 배치가 그대로 복원됩니다(**설정** > **일반** > **시작 시 레이아웃 복원** <!-- en: Restore layout on startup -->, 기본 켜짐).
