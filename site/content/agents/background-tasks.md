# 백그라운드 작업을 탭으로 가져오기

처음부터 모든 작업을 화면에 띄울 필요는 없습니다. 숨겨진 PTY에서 작업을 실행하고 출력을 확인하다가, 필요해지면 같은 프로세스와 기록을 가진 탭으로 가져오세요.

<!-- tasty-diagram: background-task -->
```
내가 읽는 로그: 그대로 | 실행 중인 숨겨진 PTY: 새 탭으로 가져오기
```

## 준비

Tasty 윈도우를 열고 그 안의 터미널에서 아래 명령을 실행하세요. `tasty` 명령이 연결되지 않으면 [CLI 준비](cli.md#준비)를 먼저 확인하세요.

여기서 다루는 것은 실행 중인 Tasty 안의 **탭 없는 PTY** 입니다. GUI 없이 서버에서 Tasty 자체를 실행하는 headless 빌드와는 다릅니다.

아래 입력 예제는 Bash, Zsh, Git Bash 기준입니다. 숫자 `2147483648`과 페인 ID `1`은 예시이므로 반드시 실제 응답에서 확인한 값으로 바꾸세요.

## 1. 탭 없이 셸 열기

```sh
tasty pty spawn
tasty pty list
```

생성 응답의 PTY ID를 기록하세요. 새 PTY는 목록에 나타나지만 화면에 탭이 생기지는 않습니다. 명령 없이 시작했으므로 셸이 입력을 기다립니다.

## 2. 명령 보내고 출력 읽기

```sh
tasty pty write --id 2147483648 $'pwd\n'
tasty pty read --id 2147483648 --lines 20
```

`write`는 받은 문자를 그대로 보냅니다. Bash 계열의 `$'...\n'`은 실제 줄바꿈을 포함하므로 명령이 제출됩니다. 일반 큰따옴표 안의 `"...\n"`과는 다릅니다.

PowerShell에서 실행한다면 입력 명령은 다음처럼 쓰세요.

```powershell
tasty pty write --id 2147483648 "pwd`n"
```

출력에 작업 디렉터리가 보이는지 확인하세요. 아직 출력이 없다면 `read`로 다시 확인합니다. 같은 방식으로 필요한 작업을 실행할 수 있습니다.

## 3. 실행 상태 확인하기

```sh
tasty pty wait --id 2147483648
```

이름과 달리 `wait`는 종료할 때까지 멈춰 있는 명령이 아닙니다. 현재 종료 여부를 즉시 돌려줍니다. 셸이 살아 있으면 `exited`는 `false`입니다. 프로세스가 끝났다면 종료 코드와 성공 여부도 확인할 수 있습니다.

셸 안에서 명령 하나가 끝났다고 셸 자체가 종료된 것은 아닙니다. PTY의 종료 상태와 개별 셸 명령의 결과를 구분하세요.

## 4. 같은 작업을 탭에서 보기

```sh
tasty list panes
tasty pty attach-surface --pty-id 2147483648 --pane-id 1
```

목록에서 고른 페인 ID를 사용하세요. **아직 실행 중인 PTY만** 가져올 수 있습니다. 프로세스와 출력 기록이 유지된 새 백그라운드 탭이 생기고, 기존 PTY ID는 `pty list`에서 빠집니다.

보던 화면은 자동으로 이동하지 않습니다. 보고 싶을 때 새 탭을 직접 선택하세요. 전환 응답에는 새 탭과 서피스 ID가 있으므로 이후 CLI 조작에는 해당 ID를 사용합니다. 이전 PTY ID로 `pty read`나 `pty kill`을 호출하지 않습니다.

## 5. 작업 정리하기

- 아직 숨겨진 PTY라면 실제 ID로 `tasty pty kill --id 2147483648`을 실행하세요. 해당 프로세스를 종료하고 자리를 회수합니다.
- 탭으로 가져왔다면 작업을 마친 뒤 그 탭을 닫으세요. 숨겨진 PTY 목록에서 정리하는 대상이 아닙니다.

숨겨진 PTY는 기본적으로 최대 8개이며, 유휴 시간이 5분을 넘으면 정리 대상이 됩니다. `read`, `write`, `wait`는 유휴 시간을 갱신합니다. 백그라운드 출력만으로 계속 보존된다고 가정하지 마세요. 오래 확인하지 않을 작업은 일반 터미널 탭을 사용하는 편이 적합합니다.

## 문제가 생기면

- PTY를 찾을 수 없으면 `tasty pty list`로 확인하세요. 이미 탭으로 옮겼거나 정리되었을 수 있습니다.
- 종료된 PTY는 탭으로 가져올 수 없습니다. 출력과 종료 상태를 확인한 뒤 정리하세요.
- 입력이 실행되지 않으면 실제 줄바꿈을 보냈는지 확인하세요.

일반 자식 터미널과 출력 읽기 기능은 [CLI 가이드](cli.md), 작업 의존성과 실패 처리는 [작업 순서 관리](tasks.md)에 있습니다.
